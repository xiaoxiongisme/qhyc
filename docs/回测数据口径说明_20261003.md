# 回测数据口径说明：continuous vs cont_adj（2026-10-03）

> 用户问："你回测使用的是什么数据，是后复权么？"
> 结论：**不是后复权，也不是前复权——是 `continuous`（tqsdk 同花顺真主连，加法平移处理过换月断层）。
> 而 PRD §4.3.5 指定的 `cont_adj` 当前已崩坏不可用。**

---

## 一、直接回答

| 项 | 我回测实际用的 | PRD §4.3.5 指定的 |
|---|---|---|
| 表 | `fut_kline` | `fut_kline` |
| **kind** | **`continuous`** | `cont_adj` |
| **符号命名空间** | **`KQ.m@SHFE.rb`** | **`RB888`** |
| 品种数 | 84 | 84 |
| 覆盖 | 2015-01-05 → 2026-09-02 | 2015-01-05 → 2026-09-02 |
| 复权方式 | 加法平移（tqsdk 主连，换月断层已消除） | 加法平移**前复权**（`cum[i] = Σ_{k>i} cc888[k]`） |
| **日线负价格** | **0 根** | **5,765 根（3.15%）** |
| 可用性 | ✅ 可用 | ❌ 已崩坏 |

**不是后复权。** 两套都是**加法平移**，但 `cont_adj` 是**前复权**（把未来换月价差加到过去，锚定最新段），
`continuous` 则是 tqsdk 直接产出的主连（换月断层由上游处理）。

### 复权类型判定依据

`scripts/adjust_bars.py`（`cont_adj` 生成器）算法注释原文：

```
前复权（锚定最新段不变）：
  cum[i] = Σ_{k>i, roll[k]} cc888[k]
  adjusted OHLC[i] = OHLC[i] + cum[i]
```

`k > i` 表示把**未来**的换月价差累加到**过去**的 bar 上 → 这是标准**前复权**定义。
PRD §4.4 标题也明写「复权标准（**加法平移前复权**）」。

## 二、★ 关键发现：两套口径的符号命名空间不同

这是本次排查最大的坑——**同一品种在两套口径下符号形态完全不同**：

| kind | 符号形态 | 命名空间 |
|---|---|---|
| `continuous` | `KQ.m@SHFE.rb`、`KQ.m@CZCE.FG` | KQ.m@ |
| `cont_adj` | `RB888`、`FG888`、`CU888` | 888 |

**后果**：查 `KQ.m@SHFE.rb` 的 `cont_adj` 会返回 0 行，容易误判"该品种没有 cont_adj 数据"。
必须先按 `kind` 分别取符号清单再 join。

> ⚠ 这与记忆里那条「同一字典表并存 IF / IF888 两形态，须双口径互证」是同类坑。

**建议修复**（尚未执行，需 CB 配合）：


## 五、两套口径的关系：恒定加法平移

同品种同日期对齐（rb 日线，2019-2022，730 个交易日）：

| 日期 | continuous | cont_adj | 差值 |
|---|---|---|---|
| 2019-01-01 | 3428.0 | 2077.0 | **−1351.0** |
| 2019-01-02 | 3444.0 | 2093.0 | −1351.0 |
| 2019-01-03 | 3475.0 | 2124.0 | −1351.0 |
| … | … | … | （恒定） |

**差值统计**：均值 −555.28 / 中位 −379.00 / 范围 [−1351, +41]（标准差 359.41）

→ 证实 `cont_adj = continuous + cum[i]`，即**恒定加法平移**（在同一换月区间内偏移量固定，
换月时跳变）。这与 `adjust_bars.py` 算法完全一致。

**推论**：两套口径的**收益率序列本应完全等价**（加法平移不改变价差）。
实测相关系数 −0.0065、日收益标准差 84.5% vs 1.64% → **cont_adj 的收益率已被崩坏污染**，
不是"另一种有效口径"，而是**数据损坏**。
