## 四、事故与处置（本轮全部实测复现）

1. **psycopg 参数上限**：`number of parameters must be between 0 and 65535`——大分片批量 INSERT 必炸；chunk-days=60（≈2,160 行×16 列）安全。
2. **postgres 崩溃恢复**：docker exec 大 COPY 导出管道断裂（SIGPIPE）触发 `automatic recovery`（redo 仅 0.12s、零数据损失），恢复窗口内新连接受拒——spot2 有 1 个分片因此跳过（fail-soft），已由自动幂等重扫兜底。
3. **pgrep/grep 自匹配陷阱**：容器内无 pgrep；`pgrep -f` 与 `grep -q 模式` 的检查命令会匹配自身 cmdline → 用 `[.]` 技巧（`collect_spot_basis[.]py`）+ /proc 扫描；waiter 守护必须**先 sleep 再首轮扫描**，否则竞态导致 repass 提前并发。
4. **两源重叠**：a/b 源 3-4 月 888 码重叠 → COPY 撞 stage 主键整文件原子回滚 → b 源改走无主键 LIKE 临时表。
5. **格式坑**：tqsdk 源 volume 为浮点格式（`18185.0`）且文件 CRLF 行尾 → 容器内 sed 去 `.0` 后缀 + 去 `\r` 后 COPY 成功。
