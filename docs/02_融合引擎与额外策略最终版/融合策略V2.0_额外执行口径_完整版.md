## 1. 策略总览（五层）

```
① 方向层（日线/小时EMA，收盘后确认）  均线方向 → 只做多 或 只做空（不顺多空都做）
            ↓ 过滤
② 入场层（小时线）                  A 回踩重启（优先） ∨ B 10根突破（补位）
            ↓ 1 手开仓
③ 离场层（小时线·额外口径）          2×ATR 初始硬止损 + 2×ATR 吊灯 + 保本(0.5R)
                                      ★ 只在「小时线收盘」击穿止损时才平仓（盘中插针无视）
            ↓
④ 执行层                          当根收盘成交 · 离场后冷却 3 根 · 单品种至多 1 仓
            ↓
⑤ 风控层                          单笔风险封顶 · 保证金上限 · 月度熔断（见 §6、§7）
```

**三条不可移除的硬约束**：① 不设固定止盈（靠 2×ATR 吊灯让利润奔跑）；② 不设结构止损；③ 移动止损只向有利方向移动，永不回撤。

## 4. 入场规则（精确，可直接照做）

### 4.1 入场 A · 回踩重启（优先）

| 侧 | 五个条件必须**同时**成立 |
|---|---|
| **多** | ① 方向层允许多 ② `C > EMA20(H1)` ③ `L ≤ EMA20(H1)`（当根最低触及均线下方）<br>④ `C > O` 且 `C ≥ (H+L)/2`（收强） ⑤ 上一根 `C < EMA20`（刚从下方穿越回来） |

### 4.2 入场 B · 10 根突破（补位）

| 侧 | 条件 |
|---|---|
| **多** | ① 方向层允许多 ② `C > 前 10 根的最高价`（**不含当根**）③ `C > O` |
| **空** | ① 方向层允许空 ② `C < 前 10 根的最低价`（**不含当根**）③ `C < O` |

### 4.3 执行细节

| 项 | 规则 |
|---|---|
| 优先级 | A 优先于 B；一根 K 线最多开 1 仓 |
| 成交时点 | **信号根自身的收盘价**（= 收盘前 5 秒挂条件单，最贴合回测；或次根开盘市价，代价约 −0.46% 总毛利，可忽略） |

## 5. 离场规则（额外执行口径 · 核心）

### 5.1 离场算法（可写进指标，已验证 0 偏离）

设入场价 `P`、入场当根 ATR14 为 `A`、持仓期最高收盘 `PK`（空头为最低收盘 `TR`）。
**额外口径关键参数：`SLK = 2.0`（初始止损 = 2×ATR，原版为 1.0）。**

```
多头：
  PK      = 自入场以来（含当根）的最高收盘
  核心止损 = MAX( P − 2.0×A ,  PK − 2.0×A )          ← 额外：初始止损改为 2×ATR
  保本触发 = PK ≥ P + 0.5×A            ← 一旦为真，永久为真（粘性）
  最终止损 = 保本触发 ? MAX(核心止损, P) : 核心止损
  离场    = 收盘价 ≤ 最终止损  → 成交价 = MIN(当根开盘, 止损价)   ★ 只看收盘价，盘中插针不触发

空头（严格镜像）：
  TR      = 自入场以来（含当根）的最低收盘
  核心止损 = MIN( P + 2.0×A ,  TR + 2.0×A )
  保本触发 = TR ≤ P − 0.5×A
  最终止损 = 保本触发 ? MIN(核心止损, P) : 核心止损
  离场    = 收盘价 ≥ 最终止损  → 成交价 = MAX(当根开盘, 止损价)
```

### 5.2 ★ 额外口径为什么这样定（最重要）

回测验证结论（48 品种逐笔模拟）：

- **原版（1×ATR 初始 + 收盘价执行）= 甲**：盈利因子 1.81、9/9 年全正 ✅
- **额外（2×ATR 初始 + 收盘价执行）= 本口径**：盈利因子 1.61、胜率更高(38.3%)、9/9 年全正 ✅
- **盘中触碰止损（无论 1×/2×/3×ATR）= 乙**：盈利因子 <1、9/9 年全负 ❌

**结论**：策略盈利只「准」在「**收盘价盯盘执行**」这一种方式。**绝不能挂盘中触碰止损单**——1×ATR 的窄止损在 1 小时 K 线噪音里会被反复扫掉（实盘模拟中 62.5% 原盈利单被盘中插针扫成保本/亏损）。额外口径把初始止损放宽到 2×ATR，单笔亏损更大但信号更干净、胜率更高，仍是 9/9 年全正的可执行版本。

**实操铁律**：每小时收盘后，只看「收盘价是否击穿止损线」决定去留；盘中上下影线一律无视，不要盘中抢跑平仓。

## 6. 风控与熔断

```
单笔风险           初始止损 = 2×ATR×乘数（额外口径）；单笔亏损有界（均值 ≈ −2R 封顶）
单品种保证金占用    ≤ 权益 8%（4 万下大多数品种 ≤ 1 手）
总保证金占用        ≤ 权益 40%（含浮亏）
同时持仓品种数      ≤ 6 个（5 池则 ≤5）；4 万小资金自然卡在 4~5 手
连亏暂停（组合层）  组合层连续亏损 ≥ 3 笔 → 暂停开新仓 10~15 天（或直到 1 笔盈利/保本恢复）
                   月度实亏 > 权益 8% → 当月不再开新仓（慢磨兜底）
月度熔断           当月权益回撤 ≥ 6% → 停止开新仓至下月 1 日；≥ 10% → 全部平仓暂停 2 周
单日熔断           单日回撤 ≥ 4% → 当日不再开新仓
禁止项             无网格、无摊平、无逆势加仓、无对冲、无隔夜重仓
```

> 熔断后恢复：先降风险预算一半运行 2 周，滚动 12 月收益转正后再恢复。

## 8. 同花顺指标代码（额外口径 · SLK=2.0 · v6 已验证 0 偏离）

> 与通用版唯一差别：`SLK := 1.0` → **`SLK := 2.0`**。其余运算符、状态机（BARSLAST 判定）、跨周期已全数修正。
> 导入顺序：先建【公式2】RHH（主图），再按需建【公式3】RHT（交易系统）。

### 【公式2】RHH —— 小时线主图（★ 主要使用）

```
N1 := 20;
N2 := 10;
N3 := 14;
SLK := 2.0;
TRK := 2.0;
BER := 0.5;
NDD := 140;
MAHD := EMA(CLOSE, NDD);
DIRP := IF(REF(CLOSE, 1) > REF(MAHD, 1), 1, 0 - 1);
OKL := DIRP >= 0;
OKS := DIRP <= 0;
MAL := EMA(CLOSE, N1);
TRU := MAX(MAX(HIGH - LOW, ABS(REF(CLOSE, 1) - HIGH)), ABS(REF(CLOSE, 1) - LOW));
ATR14 := SMA(TRU, N3, 1);
XUP := CLOSE > MAL AND REF(CLOSE, 1) < REF(MAL, 1);
XDN := CLOSE < MAL AND REF(CLOSE, 1) > REF(MAL, 1);
STRB := CLOSE > OPEN AND CLOSE >= (HIGH + LOW) / 2;
STRR := CLOSE < OPEN AND CLOSE <= (HIGH + LOW) / 2;
AL0 := OKL AND CLOSE > MAL AND LOW <= MAL AND STRB AND XUP;
AS0 := OKS AND CLOSE < MAL AND HIGH >= MAL AND STRR AND XDN;
HHN := REF(HHV(HIGH, N2), 1);
LLN := REF(LLV(LOW, N2), 1);
BL0 := OKL AND CLOSE > HHN AND CLOSE > OPEN;
BS0 := OKS AND CLOSE < LLN AND CLOSE < OPEN;
BK0 := AL0 OR BL0;
SK0 := AS0 OR BS0;
NB := BARSLAST(BK0);
NS := BARSLAST(SK0);
EPB := REF(CLOSE, NB);
EPS := REF(CLOSE, NS);
EAB := REF(ATR14, NB);
EAS := REF(ATR14, NS);
HIB := HHV(CLOSE, NB + 1);
LOB := LLV(CLOSE, NS + 1);
COREL := MAX(EPB - SLK * EAB, HIB - TRK * EAB);
BEL := HIB >= EPB + BER * EAB;
STOPL := IF(BEL, MAX(COREL, EPB), COREL);
CORES := MIN(EPS + SLK * EAS, LOB + TRK * EAS);
BES := LOB <= EPS - BER * EAS;
STOPS := IF(BES, MIN(CORES, EPS), CORES);
SP0 := NB >= 1 AND CLOSE <= STOPL;
BP0 := NS >= 1 AND CLOSE >= STOPS;
BGN := BARSCOUNT(CLOSE) < 2;
LBK := BARSLAST(BK0 OR BGN);
LSP := BARSLAST(SP0 OR BGN);
LSK := BARSLAST(SK0 OR BGN);
LBP := BARSLAST(BP0 OR BGN);
INL := LBK < LSP;
INS := LSK < LBP;
NOPOS := REF(INL, 1) = 0 AND REF(INS, 1) = 0;
ENTL := BK0 AND NOPOS;
ENTS := SK0 AND NOPOS;
EXTL := SP0 AND REF(INL, 1) = 1;
EXTS := BP0 AND REF(INS, 1) = 1;
MA20: MAL, COLORWHITE;
STOPLONG: IF(INL = 1, STOPL, DRAWNULL), COLORGREEN, LINETHICK2;
STOPSHRT: IF(INS = 1, STOPS, DRAWNULL), COLORGREEN, LINETHICK2;
DRAWICON(ENTL, LOW * 0.997, 1);
DRAWTEXT(ENTL, LOW * 0.994, '开多');
DRAWICON(EXTL, HIGH * 1.003, 2);
DRAWTEXT(EXTL, HIGH * 1.006, '平多');
DRAWICON(ENTS, HIGH * 1.003, 3);
DRAWTEXT(ENTS, HIGH * 1.006, '开空');
DRAWICON(EXTS, LOW * 0.997, 4);
DRAWTEXT(EXTS, LOW * 0.994, '平空');
```

### 指标写不进去的 8 件事 → 人工规则（必看）

| # | 写不进去 | 人工规则 |
|---|---|---|
| R1 | **持仓独占**（持仓期平均再响 1.83 次多余信号） | 入场后立刻纸面锁定 `P` 与 `A`，之后只盯自己算的止损，不再看指标绿线；持仓期新箭头一律忽略 |
| R2 | **冷却 3 根** | 离场后手数 3 根小时线，第 4 根起才接受新信号 |
| R3 | **跳空劣化成交** | 挂**条件单**；跳空越过止损时按开盘价成交，接受该价（回测已含） |
| R4 | **涨跌停无法成交** | 封板不平仓，次日开盘第一时间平（回测未建模，实盘额外风险） |
| R5 | **主力换月** | 换月后新合约重新预热 60 根小时线再接受信号；ATR 跳变，手数重算 |
| R6 | **仓位 / 手数** | 小资金固定 1 手（每品种 1 手、同时 ≤5 手）；或百分比定仓：`手数 = 权益×f ÷ (2×ATR14×乘数)` |
| R7 | **组合分配 / 熔断** | 总保证金 ≤ 40%、持仓品种 ≤ 6（5 池则 ≤5）、月度回撤 ≥6% 停开新仓 |
| R8 | **连亏暂停** | 组合层连续亏损 ≥3 笔 → 暂停开新仓 10~15 天（或直到 1 笔盈利/保本）；月度实亏 > 权益 8% 另加当月停开 |

> **R1 最重要**：指标绿线是公式自算的，与你真实持仓无关；持仓期它会因多余信号而跳变，必须自算止损。
