================================================================================
【模型1】FUSIOND —— 日线方向层
================================================================================
新建：公式 → 公式管理器 → 麦语言 → 新建指标
名称：FUSIOND
周期：日线
画线：副图

// ===== 融合策略V2.0 · 日线方向层（文华） =====
// 只输出 DIRPREV（昨日方向），供小时线跨周期引用 —— 防未来函数的关键
MA20D:=EMA(CLOSE,20);
DIR:=IFELSE(CLOSE>MA20D,1,IFELSE(CLOSE<MA20D,-1,0));
DIRPREV:REF(DIR,1);
ATR14D^^SMA(MAX(MAX(HIGH-LOW,ABS(REF(CLOSE,1)-HIGH)),ABS(REF(CLOSE,1)-LOW)),14,1);

// DIRPREV = 1  → 昨日收盘 > 昨日EMA20 → 今日（含夜盘）只做多
// DIRPREV =-1  → 昨日收盘 < 昨日EMA20 → 今日（含夜盘）只做空
// 为什么用 REF(DIR,1)：
//   日盘（09:00~15:00）最新可用方向 = 昨日      → REF(DIR,1) 正确
//   夜盘（21:00 起，已归下一交易日）最新可用 = 当日 → REF(DIR,1) 正确
//   与回测引擎 htf_avail_hour=15 口径精确等价。

【模型2】FUSIONH —— 小时线看盘指标
================================================================================
新建：公式 → 公式管理器 → 麦语言 → 新建指标
名称：FUSIONH
周期：1小时
画线：主图

// ===== 融合策略V2.0 · 小时线主图（文华看盘版） =====
// ---- 参数（需要调参改这里）----
N1:=20;      // 入场EMA周期
N2:=10;      // 突破回看根数
N3:=14;      // ATR周期
SLK:=1.0;    // 初始止损 ATR 倍数
TRK:=2.0;    // 吊灯止损 ATR 倍数
BER:=0.5;    // 保本止损 R 倍数
CDK:=3;      // 冷却根数

// ---- ① 方向层：跨周期引用日线（已滞后一日，无未来函数）----
DIRP:=FUSIOND.DIRPREV#DAY;
OKL:=DIRP>=0;
OKS:=DIRP<=0;

// ---- ② 基础指标 ----
MA20:=EMA(CLOSE,N1);
TRU:=MAX(MAX(HIGH-LOW,ABS(REF(CLOSE,1)-HIGH)),ABS(REF(CLOSE,1)-LOW));
ATR14:=SMA(TRU,N3,1);        // SMA(X,14,1) = Wilder RMA，等价于回测 ATR14

// ---- ③ 入场 A · 回踩重启 ----
XUP:=CLOSE>MA20 && REF(CLOSE,1)<REF(MA20,1);
XDN:=CLOSE<MA20 && REF(CLOSE,1)>REF(MA20,1);
STRB:=CLOSE>OPEN && CLOSE>=(HIGH+LOW)/2;
STRR:=CLOSE<OPEN && CLOSE<=(HIGH+LOW)/2;
AL:=OKL && CLOSE>MA20 && LOW<=MA20 && STRB && XUP;
AS:=OKS && CLOSE<MA20 && HIGH>=MA20 && STRR && XDN;

// ---- ④ 入场 B · N2 根突破（REF 排除当根，防前视）----
HHN:=REF(HHV(HIGH,N2),1);
LLN:=REF(LLV(LOW,N2),1);
BL:=OKL && CLOSE>HHN && CLOSE>OPEN;
BS:=OKS && CLOSE<LLN && CLOSE<OPEN;

// ---- ⑤ 原始入场条件 ----
BK0:=AL || BL;
SK0:=AS || BS;

// ---- ⑥ 止损线（保本止损由 HHV/LLV 累积极值天然实现粘性）----
NB:=BARSLAST(BK0);
NS:=BARSLAST(SK0);
PB:=REF(CLOSE,NB);
PS:=REF(CLOSE,NS);
AB:=REF(ATR14,NB);
AA:=REF(ATR14,NS);
PKB:=HHV(CLOSE,NB+1);
TRS:=LLV(CLOSE,NS+1);
COREL:=MAX(PB-SLK*AB,PKB-TRK*AB);
BEL:=PKB>=PB+BER*AB;
STOPL:=IFELSE(BEL,MAX(COREL,PB),COREL);
CORES:=MIN(PS+SLK*AA,TRS+TRK*AA);
BES:=TRS<=PS-BER*AA;
STOPS:=IFELSE(BES,MIN(CORES,PS),CORES);

// ---- ⑦ 平仓 ----
SP0:=NB>=1 && CLOSE<=STOPL;
BP0:=NS>=1 && CLOSE>=STOPS;

// ---- ⑧ 输出 ----
MA20线:MA20,COLORWHITE;
多头止损:IFELSE(NB<NS,STOPL,NULL),COLORGREEN,LINETHICK2;
空头止损:IFELSE(NS<NB,STOPS,NULL),COLORGREEN,LINETHICK2;
DRAWTEXT(BK0,LOW*0.996,'开多'),COLORRED;
DRAWTEXT(SK0,HIGH*1.004,'开空'),COLORCYAN;
DRAWTEXT(SP0,HIGH*1.004,'平多'),COLORWHITE;
DRAWTEXT(BP0,LOW*0.996,'平空'),COLORWHITE;

// ============================================================
// ★★★ 必读限制 ★★★
// 实测：持仓期间平均还会出现 1.83 次多余入场信号（3908 笔共 7151 次）。
// 无状态指标无法表达"我已持仓"，所以持仓期指标上的止损线可能被重置。
// → 开仓后立刻手工记录 P 与 A，之后按手册 §5.1 自己算止损。
// → 若要自动处理，请用【模型3】FUSIONMOD（AUTOFILTER）。
// ============================================================


================================================================================
【模型3】FUSIONMOD —— 麦语言交易模型（★ 推荐，真正可执行）
================================================================================
新建：公式 → 公式管理器 → 麦语言 → 新建模型（或"程序化交易 → 新建模型"）
名称：FUSIONMOD
周期：1小时

// ===== 融合策略V2.0 · 文华麦语言交易模型 =====
// 相比【模型2】的三点增强：
//   1) AUTOFILTER —— 文华自动过滤持仓期间的重复开仓信号，实现"持仓独占"；
//      并且 BARSLAST(BK) 取的是**过滤后的真实开仓位置**，止损线不再被重置。
//   2) TRADE_AGAIN(3) —— 同一指令 3 根内不重复执行，近似"离场后冷却 3 根"。
//   3) 连亏暂停（2026-09-13 新增）—— 本品种平亏后连亏计数 +1，连亏≥3 笔自动
//      冷却 15 个交易日（≈120 根小时线）禁止新开仓，保本/盈利单清零计数。
//      ⚠️ 仅管【本品种】；组合层（同时做 5 个品种）的合计连亏暂停需人工统计
//      （见《实盘操作手册》§6.5）。查看：副图"连亏计数"变红 ≥3 即代表本品种被冷却。

DIRP:=FUSIOND.DIRPREV#DAY;
OKL:=DIRP>=0;
OKS:=DIRP<=0;

MA20:=EMA(CLOSE,20);
TRU:=MAX(MAX(HIGH-LOW,ABS(REF(CLOSE,1)-HIGH)),ABS(REF(CLOSE,1)-LOW));
ATR14:=SMA(TRU,14,1);

XUP:=CLOSE>MA20 && REF(CLOSE,1)<REF(MA20,1);
XDN:=CLOSE<MA20 && REF(CLOSE,1)>REF(MA20,1);
STRB:=CLOSE>OPEN && CLOSE>=(HIGH+LOW)/2;
STRR:=CLOSE<OPEN && CLOSE<=(HIGH+LOW)/2;
AL:=OKL && CLOSE>MA20 && LOW<=MA20 && STRB && XUP;
AS:=OKS && CLOSE<MA20 && HIGH>=MA20 && STRR && XDN;
HHN:=REF(HHV(HIGH,10),1);
LLN:=REF(LLV(LOW,10),1);
BL:=OKL && CLOSE>HHN && CLOSE>OPEN;
BS:=OKS && CLOSE<LLN && CLOSE<OPEN;

// 原始信号
BK0:=AL || BL;
SK0:=AS || BS;

// 用 BARSLAST 取"过滤后的真实开仓位置"——AUTOFILTER 下取的是真实开仓
NB:=BARSLAST(BK0);
NS:=BARSLAST(SK0);
PB:=REF(CLOSE,NB);
PS:=REF(CLOSE,NS);
AB:=REF(ATR14,NB);
AA:=REF(ATR14,NS);
PKB:=HHV(CLOSE,NB+1);
TRS:=LLV(CLOSE,NS+1);
COREL:=MAX(PB-1.0*AB,PKB-2.0*AB);
BEL:=PKB>=PB+0.5*AB;
STOPL:=IFELSE(BEL,MAX(COREL,PB),COREL);
CORES:=MIN(PS+1.0*AA,TRS+2.0*AA);
BES:=TRS<=PS-0.5*AA;
STOPS:=IFELSE(BES,MIN(CORES,PS),CORES);

SP:=NB>=1 && CLOSE<=STOPL;
BP:=NS>=1 && CLOSE>=STOPS;

// ============================================================
// ★ 连亏暂停（2026-09-13 新增，单品种版）
//   逻辑：平亏后连亏计数 +1；连亏≥3 笔 → 冷却 15 个交易日（≈120 根小时线）
//         冷却期间禁止新开仓；冷却结束自动恢复。保本/盈利单清零连亏计数。
//   说明：本模型只管【本品种】。组合层（你同时做 5 个品种）的合计连亏暂停，
//         见《实盘操作手册》§6.5，需在交易软件里人工统计 5 个品种合计连亏。
// ============================================================
LossL:=SP && CLOSE<PB;      // 平多且低于入场价 → 亏损
WinL :=SP && CLOSE>=PB;     // 平多且≥入场价 → 保本/盈利
LossS:=BP && CLOSE>PS;      // 平空且高于入场价 → 亏损
WinS :=BP && CLOSE<=PS;     // 平空且≤入场价 → 保本/盈利
Lps:=IFELSE(SP||BP, IFELSE(LossL||LossS, REF(Lps,1)+1, 0), REF(Lps,1));
Cool:=REF(Cool,1);
Cool:=IFELSE(Lps>=3 && REF(Lps,1)<3, 120, IFELSE(Cool>0, Cool-1, 0));  // 跨越3时重置冷却
Pause:=Cool>0;

BK:=BK0 && Pause=0;       // 冷却期间不开新仓（Pause=0 才允许）
SK:=SK0 && Pause=0;

AUTOFILTER;
TRADE_AGAIN(3);

// 画线（可选）
MA20线:MA20,COLORWHITE;
STOPL线:STOPL,COLORGREEN;
STOPS线:STOPS,COLORGREEN;
连亏计数:Lps,COLORRED;        // 连亏≥3 时持续显示，辅助你判断组合层状态

// ---------------------------------------------------------------
// 若文华提示 "BK" 语法错误（老版本麦语言），把指令块改成老式写法：
//     AUTOFILTER;
//     TRADE_AGAIN(3);
//     (AL || BL) && Pause=0,BK;
//     (AS || BS) && Pause=0,SK;
//     (NB>=1 && CLOSE<=STOPL),SP;
//     (NS>=1 && CLOSE>=STOPS),BP;
// ---------------------------------------------------------------


================================================================================
导入步骤（文华6 / WH6）
================================================================================
1. 打开文华6 → 顶部菜单「公式」→「公式管理器」
   （部分版本在「系统工具」→「麦语言」或「量化」→「公式管理器」）
2. 左侧选「麦语言」→ 点「新建」
3. 类型选「指标」（模型3 选「模型」），名称填 FUSIOND，周期选「日线」
4. 粘贴【模型1】代码 → 点「语法检测」（应提示通过）→「确定」
5. 重复 2~4 建 FUSIONH（周期「1小时」，画线「主图」）
6. 使用：打开某品种 1 小时 K 线 → 主图右键 →「叠加指标」→ 选 FUSIONH
7. （程序化）建 FUSIONMOD：类型选「模型」，周期「1小时」，
   之后可在「程序化交易」→「模组」中加载并回测

--------------------------------------------------------------------------------
常见问题
--------------------------------------------------------------------------------
Q1. 提示"未定义标识符 FUSIOND" / 跨周期引用失败
A.  ① 确认 FUSIOND 已保存，名称完全一致；
    ② 引用写法必须是  FUSIOND.DIRPREV#DAY  （指标名.输出变量名#周期）；
    ③ 确认 FUSIOND 中 DIRPREV 用的是 ":" 输出（不是 ":=" 中间变量），
       否则外部引用不到；
    ④ 仍失败 → 用【降级方案】。

Q2. IFELSE / NULL 报错
A.  部分老版本用 IF 而非 IFELSE，用 0 替代 NULL：
      多头止损:IF(NB<NS,STOPL,0),COLORGREEN,LINETHICK2;
    （会多画一条 0 线，可把颜色设成与背景一致）

Q3. 逻辑运算符 && 报错
A.  改用 AND / OR ：  AL:=OKL AND CLOSE>MA20 AND ... ;
    （文华两种都支持，取你版本能通过的那种）

Q4. 夜盘方向不对
A.  文华默认"夜盘归属下一交易日"（可在 系统选项 → 时间 中确认）。
    确认方法：1 小时图上，某日 21:00 那根 K 线的日线日期是否与当日 14:00 不同。

Q5. AUTOFILTER 后信号变少了
A.  正常 —— 这正是"持仓独占"生效的表现。持仓期间的多余信号被过滤掉了。
    信号总数应接近"真实开仓数"（约等于原始信号的 35%）。

--------------------------------------------------------------------------------
【降级方案】跨周期引用实在用不了时
--------------------------------------------------------------------------------
"两屏人工法"：
  屏幕 A：日线图 —— 只回答"昨天收盘在 EMA20 上方还是下方"
  屏幕 B：1 小时图 FUSIONH —— 只接受与屏幕 A 同向的箭头
做法：把代码里
        DIRP:=FUSIOND.DIRPREV#DAY;
      改成
        DIRP:=1;        // 日线多头填 1，空头填 -1，每天手工改一次
逻辑与回测一致，只是方向层由人工维护。
