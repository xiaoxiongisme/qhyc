★ v5 → v6 改了什么（"HLD参数未定义"报错）
================================================================================
   错误行数：42
   错误语句：HLD := IF(BARSCOUNT(CLOSE) < 2, 0, IF(BK0 AND REF(HLD, 1) = 0, 1, ...
   详细原因：[语法错误]HLD参数未定义
── 真实根因：变量自引用违规 ────────────────────────────────────────
  v5 用一句 IF 嵌套写持仓锁，右侧引用了自己的上一根值 REF(HLD, 1)：
      HLD := IF(..., REF(HLD, 1), ...);          ← 自引用
  同花顺不允许"一个变量在**定义它的那一行**里引用自己的历史值"，
  于是报"[语法错误]HLD参数未定义"。报错行同样是**真凶的上一行**（第 42 行）。
  【公式3】的连亏计数 `LPS := ... REF(LPS, 1) ...` 同理报"LPS参数未定义"。

── v6 处置：改用纯 BARSLAST 状态判定，彻底不用自引用 ──────────────
  思路：不去"记录持仓状态"，而是用"最近一次开仓 / 最近一次平仓谁更近"来推断。
      BGN  := BARSCOUNT(CLOSE) < 2;
      LBK  := BARSLAST(BK0 OR BGN);     距今多少根前开过多
      LSP  := BARSLAST(SP0 OR BGN);     距今多少根前平过多
      LSK  := BARSLAST(SK0 OR BGN);     距今多少根前开过空
      LBP  := BARSLAST(BP0 OR BGN);     距今多少根前平过空
      INL  := LBK < LSP;                开多比平多更近 → 当前持多
      INS  := LSK < LBP;                开空比平空更近 → 当前持空
      NOPOS:= REF(INL, 1) = 0 AND REF(INS, 1) = 0;   上一根是空仓
      ENTL := BK0 AND NOPOS;            开多（上一根空仓才认）
      ENTS := SK0 AND NOPOS;            开空
      EXTL := SP0 AND REF(INL, 1) = 1;  平多（上一根持多才认）
      EXTS := BP0 AND REF(INS, 1) = 1;  平空
  公式3 的连亏计数同样改写为无自引用：
      LSCNT := COUNT(LOSX, BARSLAST(WINX OR BGN) + 1);
      B3    := BARSLAST(LSCNT >= 3 AND REF(LSCNT, 1) < 3);
      COOLOK:= B3 >= N4;

  校验结果（22 品种小时线复现，开仓数 = 平仓数，完全配对）：
      玻璃 FG：295 笔多头往返 + 346 笔空头往返（7 年，差 2 = 数据末端仍持有）
      近 80 根 K 线只剩 9 个标记（原先 v4 是 80 个）
      自引用变量数 = 0、无空格运算符 = 0、跨周期引用 = 0

★ v4 → v5 改了什么（"每根K线都有信号"）
================================================================================
现象：主图上几乎**每根 K 线**都被画上"开多/平多/开空/平空"文字与图标。

── 真实根因：同花顺指标公式是【无状态】的 ─────────────────────────
  公式每根 K 线都从头独立算一遍，它并不知道"我当前是否已经持仓"。
  v4 把信号画在了**原始条件**上：
      DRAWICON(SP0, ...) / DRAWTEXT(SP0, ..., '平多')
  其中 SP0（平多）= NB >= 1 AND CLOSE <= STOPL。
  止损线 STOPL 是**移动**的：价格一旦跌破多头跟踪止损，CLOSE <= STOPL
  就会**连续几十根**保持为真，直到下一次开多信号才重置 →
  "平多"被逐根重复画满屏幕。空头方向同理。

  实测（22 品种小时线复现 v4 逻辑）：
      条件覆盖 K 线比例        近 80 根覆盖
      v4 原始条件              97% ~ 99%      100%（80/80）
      其中 平多 SP0 单独        65% 的 K 线     62/80
      其中 平空 BP0 单独        71% 的 K 线     59/80
      v5/v6 加状态判定后        约 10%          9/80

── v5 处置：加"持仓状态锁"（v6 已改为纯 BARSLAST，见上节）─────────
  含义：只在"上一根是空仓"时才认开仓，只在"上一根是该方向持仓"时才认平仓，
       信号变成**事件型**（每笔只出现一次）。
  止损线也只在持仓时画：STOPLONG: IF(INL = 1, STOPL, DRAWNULL) ...

  校验结果（开仓数 = 平仓数，完全配对）：
      玻璃 FG：295 笔多头往返 + 346 笔空头往返（7 年）
      近 80 根 K 线只剩 9 个标记（原先 80 个）

  副产品：v4 说"持仓期间平均出现约 1.83 次多余入场信号"——v5 起已自动消除。

★ v3 → v4 改了什么（运算符粘连报错）
================================================================================
   错误行数：34  错误语句：LOB:=LLV(CLOSE,NS+1);
   详细原因：[语法错误]SLKEAB函数未定义
── 真实根因：运算符粘连（星号两边没有空格）─────────────────────────
  报错行虽写的是第 34 行，真正的毒点是**下一行**：
      COREL:=MAX(EPB-SLK*EAB,HIB-TRK*EAB);
  `*` 两边没有空格时，同花顺词法分析器会把 SLK 与 EAB 粘成一个词
  `SLKEAB` 当作函数名去查 → 查不到 → 报"SLKEAB函数未定义"。
  官方规则：运算符两边要加空格。✗ HIGH*1.02   ✓ HIGH * 1.02
── v4 处置：给**所有**运算符两边补空格 ─────────────────────────────
  · 乘除加减：SLK * EAB、EPB - SLK * EAB、(HIGH + LOW) / 2
  · 比较：CLOSE > MAL、NB >= 1、CLOSE <= STOPL
  · 逻辑：AND / OR 两侧保持空格；函数逗号后空格：MAX(a, b)、REF(CLOSE, 1)
  · 赋值：一律 `名称 := 表达式;`；负号改写成 `0 - 1`
  已逐字符脚本校验：两份公式中"未加空格的 * / + - > <"数量 = 0。

── 同时废止：跨周期引用 ───────────────────────────────────────────
  v3 用 DIRP:="RHD.DIRPREV#DAY"; 引日线方向，既依赖公式1、又踩"副图禁用
  跨周期引用"的坑。v4 起直接在同公式内用小时 EMA(140) 复刻日线方向：
      NDD := 140;
      MAHD := EMA(CLOSE, NDD);
      DIRP := IF(REF(CLOSE, 1) > REF(MAHD, 1), 1, 0 - 1);
  依据：22 品种 median 约 7 根小时线/日 → 日线 EMA(20) ≈ 小时 EMA(140)。

（历史备注：更早两轮报错分别是 (a) CDK 撞保留名 → 改名 RHD；
  (b) 跨周期引用 "RHD.DIRPREV#DAY" → v3 移除。至此五类坑全部封堵：
   命名特殊符号 / 跨周期引用 / 运算符粘连 / 无状态重复画 / 变量自引用。）

【公式2】RHH —— 小时线主图（★ 主要使用）
================================================================================
新建位置：公式管理器 → 技术指标 → 新建
公式名称：RHH
适用周期：60分钟（列表里可能写 MIN60 或"1小时"）
画线方法：主图叠加（★ 不要选副图——箭头按价格 LOW * 0.997 / HIGH * 1.003
          定位，画在副图会跑出可视范围）
公式代码（纯代码，可直接全选复制；推荐直接用同名 txt 文件）：

N1 := 20;
N2 := 10;
N3 := 14;
SLK := 1.0;
TRK := 2.0;
BER := 0.5;
NDD := 140;
MAHD := EMA(CLOSE, NDD);
DIRP := IF(REF(CLOSE, 1) > REF(MAHD, 1), 1, 0 - 1);
OKL := DIRP >= 0;
OKS := DIRP <= 0;
MAL := EMA(CLOSE, N1);
TRU := MAX(MAX(HIGH - LOW, ABS(REF(CLOSE, 1) - HIGH)), ABS(REF(CLOSE, 1) - LOW));
ATR14 := SMA(TRU, N3, 1);
XUP := CLOSE > MAL AND REF(CLOSE, 1) < REF(MAL, 1);
XDN := CLOSE < MAL AND REF(CLOSE, 1) > REF(MAL, 1);
STRB := CLOSE > OPEN AND CLOSE >= (HIGH + LOW) / 2;
STRR := CLOSE < OPEN AND CLOSE <= (HIGH + LOW) / 2;
AL0 := OKL AND CLOSE > MAL AND LOW <= MAL AND STRB AND XUP;
AS0 := OKS AND CLOSE < MAL AND HIGH >= MAL AND STRR AND XDN;
HHN := REF(HHV(HIGH, N2), 1);
LLN := REF(LLV(LOW, N2), 1);
BL0 := OKL AND CLOSE > HHN AND CLOSE > OPEN;
BS0 := OKS AND CLOSE < LLN AND CLOSE < OPEN;
BK0 := AL0 OR BL0;
SK0 := AS0 OR BS0;
NB := BARSLAST(BK0);
NS := BARSLAST(SK0);
EPB := REF(CLOSE, NB);
EPS := REF(CLOSE, NS);
EAB := REF(ATR14, NB);
EAS := REF(ATR14, NS);
HIB := HHV(CLOSE, NB + 1);
LOB := LLV(CLOSE, NS + 1);
COREL := MAX(EPB - SLK * EAB, HIB - TRK * EAB);
BEL := HIB >= EPB + BER * EAB;
STOPL := IF(BEL, MAX(COREL, EPB), COREL);
CORES := MIN(EPS + SLK * EAS, LOB + TRK * EAS);
BES := LOB <= EPS - BER * EAS;
STOPS := IF(BES, MIN(CORES, EPS), CORES);
SP0 := NB >= 1 AND CLOSE <= STOPL;
BP0 := NS >= 1 AND CLOSE >= STOPS;
BGN := BARSCOUNT(CLOSE) < 2;
LBK := BARSLAST(BK0 OR BGN);
LSP := BARSLAST(SP0 OR BGN);
LSK := BARSLAST(SK0 OR BGN);
LBP := BARSLAST(BP0 OR BGN);
INL := LBK < LSP;
INS := LSK < LBP;
NOPOS := REF(INL, 1) = 0 AND REF(INS, 1) = 0;
ENTL := BK0 AND NOPOS;
ENTS := SK0 AND NOPOS;
EXTL := SP0 AND REF(INL, 1) = 1;
EXTS := BP0 AND REF(INS, 1) = 1;
MA20: MAL, COLORWHITE;
STOPLONG: IF(INL = 1, STOPL, DRAWNULL), COLORGREEN, LINETHICK2;
STOPSHRT: IF(INS = 1, STOPS, DRAWNULL), COLORGREEN, LINETHICK2;
DRAWICON(ENTL, LOW * 0.997, 1);
DRAWTEXT(ENTL, LOW * 0.994, '开多');
DRAWICON(EXTL, HIGH * 1.003, 2);
DRAWTEXT(EXTL, HIGH * 1.006, '平多');
DRAWICON(ENTS, HIGH * 1.003, 3);
DRAWTEXT(ENTS, HIGH * 1.006, '开空');
DRAWICON(EXTS, LOW * 0.997, 4);
DRAWTEXT(EXTS, LOW * 0.994, '平空');

--------------------------------------------------------------------------------
参数对照表（写在文档里，不要写进编辑器）
--------------------------------------------------------------------------------
  N1  = 20   入场 EMA 周期（小时线入场均线）
  N2  = 10   N 根突破的回看根数
  N3  = 14   ATR 周期（SMA(X,N,1) 即 Wilder RMA，与回测 ATR14 一致）
  SLK = 1.0  初始止损 = 1.0 × ATR
  TRK = 2.0  吊灯止损 = 2.0 × ATR
  BER = 0.5  浮盈达 0.5R 后止损上移到成本价（保本）
  NDD = 140  方向层 EMA 周期（小时线；≈ 日线 EMA20，替代跨周期引用）

--------------------------------------------------------------------------------
图形含义
--------------------------------------------------------------------------------
  图标 1 = 开多，图标 2 = 平多，图标 3 = 开空，图标 4 = 平空
  绿线 = 当前持仓方向的止损位（空仓时不画）
  白线 = 入场 EMA
  正常密度参考：玻璃 FG 近 2 周（约 80 根小时线）约 9 个标记，
  即"一开一平"成对出现；若看到满屏标记 → 检查是否误用了 v4 及更早的代码。
  注意：图上若出现红色 1~9 数字，那是同花顺自带【神奇九转】指标，
  与本策略无关，可在副图指标里去掉。

【公式3】RHT —— 交易系统公式（可选，内建持仓状态机 + 连亏冷却）
================================================================================
新建位置：公式管理器 → 交易系统 → 新建
公式名称：RHT
适用周期：60分钟
公式代码（与【公式2】同源，多出"连亏冷却"和买卖点输出）：

N1 := 20;
N2 := 10;
N3 := 14;
SLK := 1.0;
TRK := 2.0;
BER := 0.5;
N4 := 120;
NDD := 140;
MAHD := EMA(CLOSE, NDD);
DIRP := IF(REF(CLOSE, 1) > REF(MAHD, 1), 1, 0 - 1);
OKL := DIRP >= 0;
OKS := DIRP <= 0;
MAL := EMA(CLOSE, N1);
TRU := MAX(MAX(HIGH - LOW, ABS(REF(CLOSE, 1) - HIGH)), ABS(REF(CLOSE, 1) - LOW));
ATR14 := SMA(TRU, N3, 1);
XUP := CLOSE > MAL AND REF(CLOSE, 1) < REF(MAL, 1);
XDN := CLOSE < MAL AND REF(CLOSE, 1) > REF(MAL, 1);
STRB := CLOSE > OPEN AND CLOSE >= (HIGH + LOW) / 2;
STRR := CLOSE < OPEN AND CLOSE <= (HIGH + LOW) / 2;
AL0 := OKL AND CLOSE > MAL AND LOW <= MAL AND STRB AND XUP;
AS0 := OKS AND CLOSE < MAL AND HIGH >= MAL AND STRR AND XDN;
HHN := REF(HHV(HIGH, N2), 1);
LLN := REF(LLV(LOW, N2), 1);
BL0 := OKL AND CLOSE > HHN AND CLOSE > OPEN;
BS0 := OKS AND CLOSE < LLN AND CLOSE < OPEN;
BK0 := AL0 OR BL0;
SK0 := AS0 OR BS0;
NB := BARSLAST(BK0);
NS := BARSLAST(SK0);
EPB := REF(CLOSE, NB);
EPS := REF(CLOSE, NS);
EAB := REF(ATR14, NB);
EAS := REF(ATR14, NS);
HIB := HHV(CLOSE, NB + 1);
LOB := LLV(CLOSE, NS + 1);
COREL := MAX(EPB - SLK * EAB, HIB - TRK * EAB);
BEL := HIB >= EPB + BER * EAB;
STOPL := IF(BEL, MAX(COREL, EPB), COREL);
CORES := MIN(EPS + SLK * EAS, LOB + TRK * EAS);
BES := LOB <= EPS - BER * EAS;
STOPS := IF(BES, MIN(CORES, EPS), CORES);
XLONG := NB >= 1 AND CLOSE <= STOPL;
XSHORT := NS >= 1 AND CLOSE >= STOPS;
LOSSL := XLONG AND CLOSE < EPB;
WINL := XLONG AND CLOSE >= EPB;
LOSSS := XSHORT AND CLOSE > EPS;
WINS := XSHORT AND CLOSE <= EPS;
LOSX := LOSSL OR LOSSS;
WINX := WINL OR WINS;
BGN := BARSCOUNT(CLOSE) < 2;
LSCNT := COUNT(LOSX, BARSLAST(WINX OR BGN) + 1);
B3 := BARSLAST(LSCNT >= 3 AND REF(LSCNT, 1) < 3);
COOLOK := B3 >= N4;
ENTERLONG: BK0 AND COOLOK;
EXITLONG: XLONG;
ENTERSHORT: SK0 AND COOLOK;
EXITSHORT: XSHORT;

  含义：本品种连亏 ≥3 笔后，冷却 120 根小时线（≈17 个交易日）不开新仓。
  若冷却逻辑在你的版本上异常，把 `COOLOK := B3 >= N4;` 直接改成 `COOLOK := 1;`
  即可停用暂停功能，其余买卖点逻辑完全不受影响。
  注：交易系统公式只管【本品种】连亏；组合层（5 品种合计）连亏需人工统计。
  ★ 用法提示：公式3 是"交易系统"类型，行情软件会自己维护持仓状态；若把它当
    普通指标叠加在主图上，会像 v4 的公式2 那样逐根重复画信号。日常看盘用公式2。

--------------------------------------------------------------------------------
粘贴注意
--------------------------------------------------------------------------------
· 用配套的两个"纯代码 txt"最省事，只有代码，全选复制不会带进说明文字。
· 所有符号必须**英文半角**：, ; ( ) : = 引号。
  中文逗号"，"、中文括号"（）"、中文分号"；"会直接报语法错误。
· ★ 运算符两边必须留空格：`SLK * EAB` 不要写成 `SLK*EAB`
  （否则报 "[语法错误]xxx函数未定义"）。v6 代码已全部加好空格，请勿手动删空格。
· ★ 变量不得引用自身的上一根值（如 `HLD := ... REF(HLD, 1) ...`）。
  需要状态时用 BARSLAST 比较法（v6 公式2 的 INL/INS）或 COUNT 计数法
  （v6 公式3 的 LSCNT），不要写自引用。
· 从 Word/微信/网页复制可能夹带零宽空格或不可见字符。
  若报错莫名其妙，把代码先粘进 Windows 记事本，再全选复制一次粘进同花顺。
· 若你的软件是"导入公式文件"方式：文件编码必须是 ANSI(GBK)，
  UTF-8/BOM 会被识别为空白。用记事本打开→另存为→编码选 ANSI。

--------------------------------------------------------------------------------
★ 报错/症状对照速查表（照表改，不用问人）
--------------------------------------------------------------------------------
[报错0] 公式名称"无法使用特殊符号"                    位置：新建公式时
  病因：名字里有下划线/空格/短横线/括号等（FUSION_D 的 "_" 就是）
  改法：只用中文、英文、数字。→ RHD / RHH / RHT / FUSIOND / 日线方向

[报错1] [语法错误]xxxx函数未定义（那个"函数名"像是两个变量粘在一起）
                                                        位置：运算符所在行的上一行
  病因：运算符两边没空格 → 相邻两个变量被粘成一个词。例：
        SLK*EAB → SLKEAB、HIGH*1.02 → HIGH1.02。
  改法：给所有运算符两边补空格：a * b、a - b、a >= b、a AND b；逗号后也加空格。

[报错2] [语法错误]$元素缺失,函数格式错误                位置：跨周期引用行或其上一行
  病因：引用了不存在/拼错的公式名，或版本不支持跨周期引用（副图模式尤甚）。
  改法：v4 起已彻底移除跨周期引用（方向层改为同公式 EMA(140)），此报错应不再出现。

[报错3] 语法错误,变量<xxx>未定义                        位置：注释附近
  病因：行尾挂了 {} 注释，或第 1 行就是 {} 注释 → 编译器把注释内容当成变量名
  改法：注释全部删掉，或改成 // 并独占一行；代码行末尾不留任何注释。

[报错4] 在绘图函数/文本类型函数输出下无效的输出线型       位置：DRAWTEXT/DRAWICON 行
  病因：给绘图函数加了 ,COLORxxx 或 ,LINETHICK
  改法：删掉这些后缀（v4 起 DRAWTEXT/DRAWICON 已无任何颜色参数）。

[报错5] 变量重复定义                                   位置：同名 := 出现两次
  病因：同花顺不允许对同一变量二次赋值
  改法：第二次用新名字。

[报错6] DRAWNULL 报错                                  位置：STOPLONG/STOPSHRT 两行
  改法：把这两行的 DRAWNULL 换成 CLOSE（会多画一条贴着收盘价的线，忽略即可）。

[报错7] REF/HHV/LLV 报"参数必须为常数"                  位置：停损线段
  病因：极少数版本要求 REF/HHV/LLV 的周期是编译期常数，而这里用的是动态 NB/NS
  改法：① 首选 EPB:=REF(CLOSE,NB); 改成 EPB:=VALUEWHEN(BK0,CLOSE);（等价、无动态周期）
        同理 EPS 改 VALUEWHEN(SK0,CLOSE)、EAB 改 VALUEWHEN(BK0,ATR14)、
        EAS 改 VALUEWHEN(SK0,ATR14)；
        ② 若仍报错，直接删掉从 NB:= 到 BP0:= 这两段 + STOPLONG/STOPSHRT 两条停止线，
        只留箭头（箭头照常可用，止损按手册 §5.1 人工算）。

[报错8] 箭头出现在盘中、随后又消失
  正常。指标在 K 线未收盘时按最新价计算，必须等该根小时 K 线走完再确认。

[报错9] 夜盘（21:00）那根的方向不对
  检查夜盘归属：同花顺「工具」→「选项」→「K线/周期」中确认"夜盘归属下一交易日"。

[报错10] [语法错误]xxx参数未定义（xxx 就是你正在定义的那个变量名）
                                                        位置：自引用变量所在行的上一行
  病因：变量在**定义自己那一行**里引用了自己的历史值，例：
        HLD := IF(BK0 AND REF(HLD, 1) = 0, 1, ...);   ← 报 "HLD参数未定义"
        LPS := IF(..., REF(LPS, 1) + 1, REF(LPS, 1)); ← 报 "LPS参数未定义"
        同花顺不支持这种自引用写法。
  改法：改用"两次事件谁更近"的 BARSLAST 比较法判定状态：
        LBK := BARSLAST(开仓事件); LSP := BARSLAST(平仓事件);
        INL := LBK < LSP;                    ← 持仓状态，无自引用
        连亏计数改用 COUNT(亏损事件, BARSLAST(盈利事件 OR 首根) + 1)。
        v6 公式2/公式3 已按此改好，照抄即可。

[症状1] 每根 K 线都画满"开多/平多"文字（不是报错，是画法问题）
  病因：把**原始条件**（SP0/BP0 等）直接交给 DRAWICON/DRAWTEXT。止损线是移动的，
        跌破后会连续几十根为真 → 逐根重复画。v4 及更早就是这样（实测覆盖 97%~100%
        的 K 线）。
  改法：用 v6 的状态判定（BARSLAST 比较法）生成**事件型**信号
        ENTL/EXTL/ENTS/EXTS（每笔只画一次）。若某版本连 BARSLAST 比较法都不认，
        退而求其次把最后 4 行改成"边沿触发"：
            ENTL := BK0 AND REF(BK0, 1) = 0;
            EXTL := SP0 AND REF(SP0, 1) = 0;
            ENTS := SK0 AND REF(SK0, 1) = 0;
            EXTS := BP0 AND REF(BP0, 1) = 0;
        并把 STOPLONG/STOPSHRT 两行删掉（边沿法无法判定持仓，止损线会不可靠）。

【连亏暂停规则】（必读）
================================================================================
本策略胜率约 29%，但保本率约 28%，所以"连亏几笔后要不要停"是实盘最常被问的问题。
完整量化分析见 `融合策略V2.0_实盘操作手册.md` §6.5。要点：

1) "8 池"是【可交易品种池】，不是同时满仓 8 手。
   实测同时持仓：多数时间 2~4 手，90 分位 6 手，仅 2020-05-19 短暂到过 8 手。
   小资金固定 1 手按保证金自然卡在 4~5 手，不用额外卡上限。

2) 回测引擎本来就是"单品种同时只 1 仓、平仓后才再开"，与 v6 公式2 的状态语义一致。

3) 同一时期最大连亏（按平仓时间跨品种混排，这才是同时持仓的真风险）：
     4 池 RB/HC/FG/I        最坏 10 笔（累计 −1.2 万）
     低保证金5 RB/HC/FG/BU/SP 最坏 10 笔（累计 −5,832 元）
     8 池（全）             最坏 14 笔（累计 −1.9 万）
   集中在 2021-05-28~06-03 等广谱下跌周。

4) 【交易系统公式 RHT】已内置"本品种连亏≥3 笔 → 自动冷却"，但它只管本品种。
   你同时做 5 个品种时，组合层的合计连亏仍需人工统计。

5) 若你只用【公式2】RHH，连亏暂停只能人工做：
   · 准备一张表：5 个品种 × 最近平仓结果序列（赢 / 保本 / 亏）。
   · 每笔平仓后，在序列末尾记一笔；从末尾往前数连续"亏"的个数。
   · 连续"亏" ≥ 3 笔 → 暂停开新仓 10~15 天（或直到出现 1 笔盈利/保本再恢复）。
   · 一笔"保本"即清零连亏计数（保本已锁住本金，风险状态解除）。
   · 另加一道【月度亏损上限 8%】兜底"被赢利打断的慢磨"。

★ 重要限制（必读）
================================================================================
1) v6 的持仓状态（INL/INS）是**公式自算**的，与你账户的真实持仓无关。
   若你漏看一根 K 线、或中途手工平仓/加仓，两者会错位 → 止损线不可直接照抄。
2) 正确做法：开仓后立刻手工记录 P（入场价）与 A（入场当根 ATR14），
   之后按《实盘操作手册》§5.1 的公式自己算止损，指标线只作参考。
3) 同花顺公式无法表达组合层的资金约束（最多 5 品种、4 万本金），
   组合层规则请按手册执行。
4) 数据口径：回测用**主连（复权）**小时线。个别品种（如甲醇 MA）本地缓存
   仅到 2021-08，看盘时请以主力连续合约为准。
