## 1. 审视方法

按策略工程全流程逐段对照 PRD 现有章节，检查每环节是否闭合：

```
数据(§4+§4A) → 因子(附录B) → 策略(§6+§6A) → 回测(§8) → 【执行?】 → 【风控?】 → 推送(§7) → 运维(§11) → 【备份/监控?】 → 治理(§13+待验证清单) → 【上线准入SOP?】
```

- 实线段：PRD 已有专章，且经 grill-me 拷问与 §4A 细化后达到"开发可照做"粒度。
- 【?】段：全流程走完后发现**无对应章节或仅一两行带过**，逐项展开见 §2。
- 交叉引用：《测试报告_20261001.md》的 ❌ 项、《复权口径切换与5分钟复权_任务清单与风险评估_20260930.md》（归档）的阶段划分、10-01 五项拍板。

## 3. 顺带发现：§14 过时表述（修订候选，非新缺口）

**§14 复审要点第 2 条（L648）**：「口径铁律：信号只读 `hourly_bar` 单一 src；**回测只读 `fut_kline.continuous`**；无双源混读；涨跌 `close` 口径。」

- 10-01 拍板已将 `DEFAULT_CALIBER` 改为复权口径、等差后复权=唯一回测口径（§4.3.5 修订块）。§14 第 2 条的"回测只读 fut_kline.continuous"是切换前口径，两处表述并存会让复审者无所适从。
- **建议修订**（等拍板）：第 2 条改为"回测只读策略显式声明的 caliber（目标=等差后复权 raw+offset；过渡期 fut_kline.continuous 前复权仅限点数差/ATR、禁止除法）；信号与回测不得混用不同 caliber"。
- 同理 §14 第 1 条"单一真源"不涉及口径，无需动。
