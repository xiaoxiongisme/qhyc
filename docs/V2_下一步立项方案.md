## 1. 决策背景：为什么现在必须立项，而不是继续挖 V2

V2 融合策略的「样本外崩塌」已用**严格 walk-forward OOS（23 窗、train720/test60/step60/warmup150）+ 真实逐手净 R（真实乘数 / 历史费率 / 加码）**口径彻底定位，三条主线全部走完：

| 主线 | 结论 | 证据 |
|---|---|---|
| 入场质量（§8.7 拆解） | 边真实但被快亏集群 + 空头系统性偏弱淹没 | 12,538 笔：胜率 28.4%、净 R −0.098、PF 0.82；≥31 根存活成交 PF 22.5，但 ≤10 根快亏占 34.5% |
| 入场质量门（§8.8 过滤） | 有**真实但不足**的信号，救不了崩塌年 | C_final 最佳：净 R −0.098→−0.058（+41% 减亏）、PF 0.82→0.893、砍 34% 单，pl_ge%≈0（真信号）；但 **2025 = −0.103 仍崩** |
| Regime 自适应减仓（§8.9） | **反向选择器**，证伪 | 所有减仓方案安慰剂% = 100（随机砍同数都比按 regime 砍更好）；市场 regime 指标全部**倒置**（多头排列/强趋势桶反而更亏），唯一盈利口袋是高波动（被减仓砍掉）；**2025 无人救援** |

**核心教训**：V2 融合 alpha 是**已结构衰减的 old-school 趋势跟随**，边在**源头**消失——不是设定、参数、入场噪声或减仓时机能救的。过去几个月追着「调参 / 挖入场 / 调仓」走，在组合层面全是安慰剂。

**因此本立项的第一原则**：**停止在 V2 现有 alpha 上继续投入**，把研究预算从「修复一个衰减信号」转向「找到/建出一个尚未衰减的信号」，并用 V2 排查中**已验证严谨的 WF-OOS 研究底座**作为所有新信号的统一评估标尺。

## 2. 战略选项与权衡

| 选项 | 描述 | 优点 | 风险 / 代价 |
|---|---|---|---|
| **A. 退役 V2 趋势腿** | 冻结 V2（SL1.0/TR6.0 不晋升），转入影子/监控，不再作为可晋升策略 | 止损沉没成本；释放研究精力 | 若融合引擎其余腿无独立 alpha，则整体无生产候选 |
| **B. 新信号源立项** | 探索与趋势跟随低相关的全新信号（基本面/跨市场/微观结构/统计套利等） | 可能找到低衰减、未拥挤的边 | 探索有失败率；需新数据接入 |
| **C. 学习型 regime 切换** | 用模型（非手工规则）学 regime→边的非线性映射，做自适应暴露 | 直接回应 §8.9「倒置/非线性」铁证 | 过拟合风险高；需严格 OOS 护栏 |
| **D. 双轨（A+B / A+C）** | 冻结 V2 的同时并行探索 B 或 C | 进可攻退可守；不赌单一方向 | 资源分散，需分阶段优先级 |

**关键判断**：A 是必选项（冻结 V2，停止沉没），不是「要不要」而是「如何收口」。争议在 B 与 C 的优先级。

## 3. 推荐路径：冻结 V2 + 双轨探索（A 必选，B 优先、C 作为 B 的护栏增强）

1. **冻结 V2**：`SL1.0/TR6.0` 维持不晋升；生产侧保持当前钩子进入的代码不变；研究侧 V2 相关脚本留档于本分支，不再迭代参数。
2. **主线 B（新信号源）优先**：趋势跟随是商品期货里最拥挤、最早衰减的类别之一；转向**与趋势低相关**的来源更可能找到低衰减边。
3. **C 作为 B 的护栏而非独立救世主**：若 B 的新信号仍显示 regime 依赖，再用学习型切换做自适应，而不是先用 C 去「修」一个已知衰减的信号。
   → **§13 判定结果（2026-11-02）**：B3 未显出 regime 依赖（8/8 分区全正、训练期预测力 OOS 反号），
   故 C 不启动、维持待命；与 §8.9「朴素减仓是反向选择器」的教训一致。
4. **统一评估底座**：复用 `scripts/alpha_entry_quality.py` + `*_oos.py` 系列（WF-OOS 23 窗 + 真实净 R + 安慰剂对照）作为每个候选信号的**准入闸门**，不允许「连续回测毛 R 漂亮」就晋级。

## 4. 新信号源候选方向（B 的具体清单）

> 筛选标准：① 与趋势跟随**低相关**（抗同一种衰减）；② 在商品期货**有数据可得**；③ 能在现有 WF-OOS 底座上快速验证。

| # | 方向 | 逻辑（为何可能低衰减） | 数据需求 | 可行性 |
|---|---|---|---|---|
| B1 | **期限结构 / 基差 carry** | 展期收益（近月−远月）是商品中已知最稳健、低拥挤的来源之一，属「持有即收租」非方向博弈 | **§12 已证数据现成**：`l0_raw.contract_daily` 3461 真实月份合约 + `spot_basis` 12 年基差率 | **§14 已完成、退役**：误判撤销后严格评估 2024–26 无稳健正边（理论微正格系前视假象） |
| B2 | **库存 / 仓单基本面** | 慢变量、难被高频套利抹平；库存周期驱动的中期定价偏离 | **§12 已证在库**：`warehouse_receipt` 6+ 年（89.7 万行）；`inventory` 仅 5 个月须弃用 | **高（改用仓单口径）** |
| B3 | **跨品种统计套利 / 配对** | 截面均值回复，与单品种趋势正交；拥挤度低 | 相关性矩阵 + 价差序列（数据现成） | 高 |
| B4 | **跨市场 / 宏观驱动** | 股债商汇的跨资产轮动信号，独立于商品自身趋势 | **§12 已证在库**：`spot_basis` / `macro_china` 月度 / `roll_yield` / 会员持仓；主工作时点对齐 | 中→高 |
| B5 | **微观结构 / order-flow 失衡** | 更高频、非方向、机构行为驱动；与日线趋势正交 | 逐笔/盘口（数据成本高，优先级靠后） | 低（先验证可行性） |
| B6 | **波动率风险溢价** | 做空过度溢价波动的截面/时序信号，与方向趋势弱相关 | 已实现波动 + 隐含（需期权数据） | 中 |

**首轮建议**：B1 + B3 先跑（数据现成、与趋势正交、验证快）；B2/B4 并行做数据接入；B5/B6 列入二期。

## 6. 准入与淘汰门槛（防安慰剂、防又一次沉没）

每个候选信号**必须全部满足**才算「可晋级影子」，否则 **kill**：

1. **WF-OOS 净 R > 0** 且 **PF ≥ 1.10**（不是「少亏」就算赢）。
2. **分年稳定**：2024 / 2025 / 2026 **每一年**净 R > 0 或至少非负（直接回应 V2 的 2025 崩塌——任何在 2025 仍崩的信号直接 kill）。
3. **过安慰剂**：标签置换 300 次，`pl_ge% < 5%`（保留集须显著优于随机同结构子集）。
4. **与 V2 低相关**：新信号日级盈亏与 V2 历史盈亏相关系数 < 0.3（确保真在补正交边，而非换皮趋势）。
5. **OOS 不退化**：train/test 窗口滚动下，后期窗口不得出现 PF 单调塌方（防止「早期有效、近期衰减」重演）。

**淘汰即归档**：未过闸的信号写入「已否决清单」附原因，避免重复探索。

- **底座一致**：新信号评估必须用 §8 验证过的 WF-OOS + 真实净 R + 安慰剂，禁止退回「连续回测毛 R 漂亮就信」。
