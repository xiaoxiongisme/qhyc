### 2. M4.1 LSTM 泄漏根治 ✅（本轮最重要的成果）
- **机制**：权重快照带 `train_until`（`{symbol}__{YYYYMMDD}.pt`），回测点只加载 `train_until ≤ 评估日` 的最新快照，无合格快照则 LSTM 诚实缺席；walk-forward 分段重训（每 60 根）。
- **数据**：424 个快照覆盖 73 品种；**0 个品种存在"评估日早于最早快照"的违规**。
- **效果**：LSTM 跨品种 dir_acc 从修复前 0.614 → **0.511**，与其他模型（0.499）差距从 +11.9pp 收敛到 +1.2pp（p=0.054，不显著）；单整批 run 检验 LSTM p=0.72，完全随机水平。**泄漏消除的验收标准达成。**
- 线上权重（73 个 `{symbol}.pt`）与回测快照隔离（`update_current=False`），回测不再污染线上。
