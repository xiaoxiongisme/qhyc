## 0. 先看结论（一句话）

> **git 不是当前的真实状态。** 生产环境实际运行的代码 = git 里的代码 + 5 个未提交改动 + 28 个从未提交的脚本 + 一整个被 gitignore 的 `runtime/` 目录 + 云端容器里被手工打过的补丁。任何一台机器从 git 全新克隆 + 构建镜像，**得到的系统跑不起来**（复权、同步、因子计算、fut_kline 重建全部缺文件）。

## 8. 三方对照总表

| 对象 | git | 本地 | 服务端(容器/镜像) | 判定 |
|---|:--:|:--:|:--:|---|
| `app/`（生产代码） | ✅ | ✅(挂载，含 5 处未提交改动) | ✅(镜像内) | 分叉（未提交改动） |
| `scripts/` 已提交部分 | ✅ | ✅ | ✅ | 一致 |
| `scripts/` 未提交部分（28 项） | ❌ | ✅ | ❌ | **P0：云端缺失** |
| `runtime/`（含复权脚本） | ❌ ignore | ✅ | ❌ ignore + 空卷 | **P0：云端缺失** |
| `config/*.yaml` | ❌ ignore | ✅ | ⚠️ 取决于构建机 | **P0：不可复现** |
| `web/dist` | ❌ ignore | ✅(挂载) | ✅(镜像构建产物) | 双来源，易冲突 |
| `db/init/*.sql` | ✅ | ✅ | ✅ | 一致（但已有库不会重跑） |
| 数据库数据 | — | 本地库（缺分钟线） | 云端库（全） | **严重分叉** |
| 云端容器内 patch | ❌ | ❌ | ✅ | **分叉，应回滚** |
| `docs/` 早期文档 | 已删未提交 | 已删 | — | 文档缺失 |
