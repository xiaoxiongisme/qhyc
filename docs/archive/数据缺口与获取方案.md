## 2. 逐项：缺什么 / 什么类型 / 从哪获取 / 能否爬取

### 2.1 展期收益率 `roll_yield`（期限结构因子）
- **缺什么**：每品种每交易日的 `(roll_yield, near_contract, far_contract)`，即近月与主力（或远月）价差月化。
- **数据类型**：日频 × 品种（非合约级），免费源直出。
- **获取方式**：**akshare `get_roll_yield(date='20240102', var='RB')`** —— 免费接口，直接返回三元组。
- **是否已就位**：✅ **采集器已存在** —— `app/ingest/roll_yield.py`，含 `fetch_roll_yield()` / `run(date, vars_list)` / 幂等 `INSERT ON CONFLICT`，`src='akshare:get_roll_yield'`，`__main__` 可单跑 RB/CU/I。
- **为什么是 0 行**：`app/scheduler.py` **没有 `roll_yield` 作业**（只有 warehouse / rank_position / inventory_weekly / spot_basis_daily）。采集器写好但从未接入调度、从未批量跑。
- **能否爬取**：**不需要爬取**，akshare 免费 API 直取。
- **前置动作**：新增调度作业（或先手动按日批量回补）。⚠️ 注意：该接口历史深度需实测（可能仅近期可按日取），回补前先用 `check` 模式探边界，**不要抽样几天就下结论**（探针文档已警告此类误判）。

### 2.2 现货基差 `spot_basis`
- **缺什么**：每品种每日 `spot_price / dominant_contract_price / dom_basis / dom_basis_rate`。
- **数据类型**：日频 × 品种（大写代码）。
- **获取方式**：**akshare `futures_spot_price_daily(start_day, end_day)`**（生意社，约 40 个商品品种），一次可取区间。
- **是否已就位**：✅ 采集器 + 调度作业**都已存在**（`scheduler.py` 有 `spot_basis_daily`，id 已注册）。
- **为什么只有 8 天**：该作业 **默认 `enabled=False`**（`详细设计` §3.4 明确"需手动或配置开启"），库里 432 行来自 09-18 那次手动跑，之后没再跑。
- **能否爬取**：**不需要爬取**，akshare 免费。
- **前置动作**：配置 `spot_basis.enabled=true` + 回补历史区间 → `docker restart qhyc-scheduler`。

### 2.3 会员持仓排名 `member_position_rank`（持仓类 / 对冲压力）
- **缺什么**：2015–2019 历史缺失（现最早 2023-01-03）；DCE 覆盖最弱。
- **数据类型**：日频 × 合约 × 会员 rank 1–20 的多/空/成交量持仓。
- **获取方式（按所）**：
  - SHFE `ak.get_shfe_rank_table(date)`（**不传 `vars_list`**）
  - CZCE `ak.get_rank_table_czce(date)`（**必须丢弃"纯字母无数字"的品种级键**）
  - GFEX `ak.futures_gfex_position_rank(date)` / CFFEX `ak.get_cffex_rank_table(date)`
  - DCE **必须 Scrapling 真浏览器**（官网瑞数动态防护，requests/curl_cffi/akshare 一律 412）
- **能否爬取**：**部分必须爬取** —— DCE 已落地 `app/ingest/dce_scrapling.py`（或 `scrapling-qi` 技能脚本）；其余四所为免费 API，不需爬。
- **⚠️ 历史上限（实测，已跑满）**：
  - SHFE / CZCE → **2023-01-03**（缺口 0，已跑满）
  - GFEX → 2023-11-10（上市起）
  - DCE → 官方**仅保留约 1 年**
  - **2015–2019：源端无留存 → 不可得**。这是硬边界，`PRD与验收差距分析` A2 的"回溯到 2015"在免费源下**不可达**，建议下调该验收目标而非继续等。

### 2.4 库存 `inventory`
- **缺什么**：历史深度（现仅 87 天 ≈ 12 周）。
- **数据类型**：周频 × 品种（库存 / 增减）。
- **免费源**：东财 `ak.futures_inventory_em(symbol=小写代码)`（回退源，**每品种仅约 72 行**）+ CZCE 官方 `futures_warehouse_receipt_czce`。
- **为什么只有 87 天**：调度作业 `_inventory_job` 用的正是 `INV.collect_inventory_em`（东财），而东财每品种只给约 72 行 → **免费源深度上限约 2–3 个月**。
- **能否爬取**：**免费源拿不到更多**；社会库存 / 开工率 / 产量 / 进出口 / 上下游利润 = **付费墙（钢联 / 百川 / 卓创）**，爬取不可得（需付费账号）。
- **结论**：**库存因子在免费源下样本过短，不建议做**（若要做得付费采购）。这正是探针文档"诚实边界"已声明的部分。

### 2.5 仓单 `warehouse_receipt` —— ✅ 唯一充足
- 720,967 行 / 664 天 / 2020-07-02 起，**数据充足**。来源为交易所官方（SHFE `.dat`、CZCE `.xls/.xlsx`、DCE+GFEX 走 Scrapling）。
- **无需补数据，可立即推进仓单因子评估**（原文称年化 6–13%、波动约 8%）。

### 2.6 宏观 `macro_china`（通胀贝塔 / 国家因子）
- 461 行 / 7 指标（PMI / CPI / PPI / M2 / 新增信贷 / RRR 等）/ 2020-01 起。
- **获取**：akshare 7 个宏观函数，免费，**不需要爬取**；当前只到 2020 是采集配置所致，可扩拉更长历史。
- 备注：国家因子（R²≈93% 解释商品指数）属**横截面系统性因子**，我们是单边顺势策略，用途有限 → P2。

### 2.7 `contract_daily`（自算期限结构的替代路径）
- 仅 6,338 行 / 64 天 → **不足以自算历史展期收益率**。
- 结论：**优先直接用 `akshare get_roll_yield`，不必走"拉全合约日线自算"的路线**（成本高、且 天勤 全合约历史需长耗时回填）。

## 4. 建议执行顺序（成本从低到高）

1. **P0 · 展期收益率回补**（最高性价比）：跑 `app.ingest.roll_yield.run(date, vars_list)` 批量回补 + 新增调度作业。原文评为"预测力最强、最稳健"（3 日年化 6.5%、夏普 0.96），且我们**零成本可补**。
2. **P0 · 现货基差开调度**：`spot_basis.enabled=true` + 区间回补 + restart。
3. **P1 · 仓单因子评估**：数据已足（664 天），直接进 E1–E6 准入。
4. **P1 · 持仓排名**：SHFE/CZCE 已跑满至 2023-01，够用；**把 A2"2015 起"目标下调为"2023-01 起"**（源端无留存）。
5. **P2 · 宏观扩历史**：拉更长区间备通胀贝塔。
6. **不做 · 库存因子**：免费源深度仅约 72 行/品种，样本不足；除非采购付费数据。

> 通用约束：长回补**多所串行**（Windows Docker WAL EINTR 会压崩实例），容器内用 `docker exec -d`；改采集器后须 `docker restart qhyc-api qhyc-scheduler`（只读挂载不热重载）。
