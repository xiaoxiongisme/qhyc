## 诊断：钱是怎么亏的

| 项 | 数值 | 含义 |
|---|---|---|
| 毛利合计 | **+33.9 万** | 信号方向本身有效 |
| 成本合计 | **−44.1 万** | 手续费 + 往返 1 跳滑点 |
| 净利 | **−10.3 万** | **成本吃掉全部毛利还倒亏** |
| 成本/毛利 | **130.3%** | 频率问题的直接度量 |
| 成交笔数 | 6,497 笔 | 每品种每年约 11.8 笔 |
| 胜率 | 21.9% | 趋势跟踪的正常区间（不是问题） |
| 逐年 | 4 正 / 7 负，2024 单独 +16.0 万 | 无稳定年份，2024 占全部利润的 155% |

**结论**：这是典型的**边际递减**——单笔期望为正（毛利/笔 = +522 元），但每笔都要付 679 元成本。**盈亏平衡需要单笔毛利提升 30%，或交易频率下降 30%。**

## 优化方向（按性价比排序）

### 第 1 位：提高单笔毛利（不降频）

**核心逻辑**：成本是固定的 ¥679/笔（按 SPEC 真实费率），单笔毛利 ¥522 → 亏。要么让毛利涨到 ¥850，要么笔数降到 4,500。

| 手段 | 具体做法 | 依据 |
|---|---|---|
| **① 收紧入场门控** | `adx_min` 从 15 上探（PRD 记「≥20 转亏」是**旧引擎**结论，引擎已变必须重测） | 直接砍掉弱趋势的假信号，单笔质量上升 |
| **② 斐波容差重扫** | `fib_tol_atr` 现 0.5。注意：PRD 记「三维度均无优化空间」也是**旧引擎**结论 | 斐波只作用 A 支路（占信号 18%），收紧可减少噪声入场 |
| **③ 关掉加码** | `add_max_lots: 2 → 1` | 3,088 笔加码单（占 47.5%）。V3.4 文档自陈"加码单约 53% 以亏损结束"——在负期望基线上，加码是纯粹的放大器 |
| **④ 延长最小持仓** | 加"入场后 N 根内不反向/不离场"约束 | 当前大量 1-3 根的极短持仓被 2×ATR 止损扫掉，等于白付两次成本 |

**预期**：③ 最值得先试（一个参数、直接砍 47.5% 笔数的手数放大），②④ 次之。

### 第 2 位：分层降频（结构性）

- **按品种波动率分流**：高波动品种正常持仓，低波动品种放宽或跳过（波动率只用于**降频**不用来**择时**——上轮已证实择时无效）
- **同品种去重**：当前同品种短期内反复进出（cooldown_bars=3 可能过短），加"同一品种两次入场最小间隔"
- **组合层节流**：现有 5 仓容量，但可加"当日新开仓上限 N 笔"

### 第 3 位：成本结构本身

- 换手续费更低的合约/月份（SPEC 显示 SC 0.1/20、AU 0.02/10、LC 20/8 等高价差品种拖累明显）
- 拉长持仓周期：同样的信号，持有到 2×ATR 吊灯而不是被短期波动扫出

### 第 4 位：品种池结构性缺陷

16 个品种长期单边 → 策略只做顺势侧 → 系统性不参与。**这不是 bug，但意味着"50 品种"实际只有约 34 个在交易**。要么接受（只做有趋势的品种），要么给单边熊市配一套独立规则（那是另一个策略的活）。

### 第 5 位：参数网格调优（**明确不建议**）

原因见上：成本占毛利 130% 的结构下，调参是拿"过拟合"换"看起来好转"。**必须先做完第 1-2 位、基线转正，再考虑调参。**
