## 0. 先看结论（5 条）

1. **代码分三大坨，职责边界模糊**：`app/`（容器里跑的生产代码，进镜像）、`scripts/`（CLI ＋ 一次性回填，部分进镜像）、`runtime/`（**250+ 个调试/研究脚本，被 gitignore，不进镜像**）。
2. **`runtime/` 里有调度器依赖的生产脚本** —— `runtime/_adjust_bars.py`、`runtime/_adjust_minute.py` 被 `app/scheduler.py` 定时调用，但 `.dockerignore` 明确排除 `runtime` → **云端容器里这两个脚本不存在，复权作业每天静默失败**（详见 03/05 号文档）。这是当前最严重的部署断裂。
3. **融合策略 V3.4 的信号层与回测层做到了"单一真源"**（`fusion_backtest` 直接复用 `walk_fusion_states`），这一条做得好。
4. **回测存在两套并行的实现**：容器内 `app/backtest/*`（M4，日线预测模型回测）与本地 `runtime/bt_engine_min15.py`（15 分钟全品种策略回测，本轮新增，**不在 git**）。两者口径、周期、成本模型都不同。
5. **因子库"实现了但没接线"**：`app/factor/asof.py` 已实现 asof_join / FactorContext / 偏置乘子（T2/T3/T5/T6），但 `compute_factor_value.py` **未接入 scheduler**，且注册表仅 11 条。

## 4. 融合策略 V3.4：规则与代码实现（重点）

**代码位置**：`app/strategies/fusion_signal.py`（829 行）
**参数来源**：`config/local.yaml` → `fusion:` 段
**主周期**：**小时线**（`hourly_bar`，akshare 口径，`hourly_src: akshare` 杜绝双源混读）

### 4.1 规则全集

| 层 | 规则 | 参数 | 实现位置 |
|---|---|---|---|
| **方向层** | 小时线 `EMA140` 定多空；用**上一根**方向对齐（无前视） | `ema_k=140` | `htf_dir` 传入 |
| **入场** | MA20 **回踩**（顺势回踩）+ **突破** 两支路 | `ma_n=20`, `entry_mode=both_nm` | `fusion_state()` |
| **趋势门控** | 小时线 `ADX(14)` < 15 → 放弃本根入场（用上一根判定） | `adx_n=14`, `adx_min=15.0` | L301 |
| **斐波汇流 (P0)** | 回踩极值须落在 0.382/0.5/0.618 位 ± `0.5×ATR` 内（**只作用于回踩支路**） | `fib_confl=true`, `fib_ratios`, `fib_tol_atr=0.5` | L262-296 |
| **初始止损** | 入场 ∓ `2.0×ATR` | `sl_atr=2.0` | — |
| **移动止损** | 吊灯：`peak − 2.0×ATR`（多）/ `trough + 2.0×ATR`（空） | `trail_atr=2.0` | L204-226 |
| **保本** | 浮盈 ≥ `0.5×ATR` 触发保本。**注意：`be_r × ATR`，不再乘 sl_atr**（V3.4 修正，旧式在 sl_atr=2.0 下被动放大成 1.0×ATR） | `be_r=0.5` | L208/226 |
| **阶梯加码 (P1)** | 开仓恒 1 手；加码条件 = 收盘创入场以来新高/新低 **且** 浮盈 ≥ `lots × 1.0 × ATR`（金字塔，门槛随手数线性抬升） | `add_max_lots=2`, `add_thr_atr=1.0` | L326-339 |
| — | V3.2 的"吊灯须推进到加码后均价之上"结构保本约束 **自 V3.4 停用**（实测损失 19.6% 收益）；代价：约 53% 加码单以亏损收场（中位 −0.16R） | `add_guard_atr=0.0` | L156 |
| **冷却** | 平仓后 3 根不再入场 | `cooldown_bars=3` | — |
| **执行** | **收盘价执行**（`closed_bars_only=true`，防信号重绘，与回测口径一致） | — | — |
| **新鲜度** | 最新 K 超过 90 分钟 → 抑制状态变化信号 | `stale_minutes=90` | — |
| **推送** | :05/:35 扫描；心跳播报每 30 分钟；开仓信号 120 分钟内复提；吊灯移动 ≥0.5ATR 推一条 | `heartbeat_interval_min=30` 等 | `_fusion_scan_job` |

### 4.2 单一真源设计（做得好的一点）

```
walk_fusion_states()   ← 信号层主循环（逐帧 yield）
    ├── 线上实时：fusion_state_detail() 包装 → 只取最后一帧
    └── 回测：   app/backtest/fusion_backtest.py 直接复用同一循环
```
即 **实时引擎与回测引擎共用同一套信号循环**，避免了"图上信号 ≠ 推送信号"的经典问题。

### 4.3 因子接入点

`fusion_signal.py` 内置 `_get_factor_ctx()`（L44），通过 `FactorContext` 读取因子并生成两个乘子：
- `position_cap_scalar` → 缩放 `add_max_lots`（L183：`_eff_cap = round(add_max_lots × position_cap_scalar)`）
- `entry_gate` → 入场闸门

⚠️ **但 `factor_value` 目前没有接入调度** → 线上这条支路实际拿不到因子数据。

## 5. 回测方法（重点）

### 5.1 容器内 M4 回测（`app/backtest/engine.py`，510 行）

- **对象**：预测模型（15 个模型）的方向准确率，不是策略盈亏。
- **方法**：逐评估点（step 间隔）构造"截至当日"特征（**防前视**），跑门控内全部模型，与**次日真实涨跌** `ret_close`（t→t+1）对比。
- **指标**：per model 的 `dir_acc`、幅度 MAE/RMSE、分位覆盖命中 `quantile_hit`、样本数、Hurst 状态分层。
- **产出**：`backtest_result`（聚合）+ `backtest_detail`（明细，逐评估点）。
- **权重联动**：`weights.py` 按近 60 日准确率月更 `w = clip((acc−0.5)×8+0.3, 0.1, 2.0)`。
- **成本**：`cost_pct: 0.065`（单边，手续费+滑点）。
- **审计**：`scripts/audit_m4*.py` 系列（4 个版本）+ `review_*.py`（15 个根因排查脚本）—— 说明历史上出过多次口径事故（reversal 0.5000 bug 等）。

### 5.2 融合策略回测（`app/backtest/fusion_backtest.py`，360 行）

- 复用 `walk_fusion_states` 信号层 + 研究侧 **容量 5 FIFO** 回放 + `real_cost(1.0)`。
- 验收锚点（`scripts/accept_v34.py`）：生产真数据源 `fut_kline` 连续主连上，events=16400 / executed=3226 / win_rate=…。

### 5.3 本地 15 分钟全品种引擎（`runtime/bt_engine_min15.py`，**不在 git**）

本轮新增，用于评估三个"可融入点"与 A 隐秘数轴。要素：

| 项 | 口径 |
|---|---|
| 数据 | 50 品种 × 312 万根 15m bar（`bar_15m` raw / `fut_kline` cont_adj） |
| 价格口径 | `continuous`（未复权）为回测基准；`cont_adj` 仅统计/交叉验证 |
| 成交 | **收盘价执行**（close-only） |
| 收益换算 | `¥ = R × risk(2×ATR) × mult − 往返成本`；成本 `bp/2/1e4 × (ep+xp) × mult` |
| 组合层 | FIFO + `max_pos` 容量门控；同品种同时单仓 |
| 净值曲线 | **等权**：每品种累计净¥ → 按日 reindex + ffill → 跨品种 mean → 算 MDD |
| 稳健性 | 对称性自检 / 时间分半 / 逐年 / 参数平台 / 成本扫描 / 随机入场 MC + bootstrap / Top5 集中度 |
| 走前 | 锚定式 2019–2026 |

**主要结果**（50 品种 5bp 容量5）：融合基线 +16.3万(PF1.03) / ADX≥15 +19.8万(MAR1.17) / 关键线过滤 −15.4万 / 3K −17.2万 / **A 隐秘数轴 +259.8万(PF1.67,胜率58.1%,逐年12/12)**。
