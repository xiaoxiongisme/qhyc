## 二、复权（B 操作）的真实落地路径

**重要前提：系统里"复权"早就是定时任务**——`app/scheduler.py` 的 `_adjust_job` 每天 **02:30** 跑 `adjust_fdf.run(key, freq)`，对全部主连品种生成 `fut_kline.cont_adj`。但**只覆盖 `daily` + `hourly`，没有 `min15`**。所以"复权需要做定时任务"其实已具备，缺口是 **15m 没进循环**，且 **15m 源数据缺失**。

### 2.1 三类"复权版"各自落点

| 目标       | 复权版应落点                                 | 原版保留                        | 现状            |
| -------- | -------------------------------------- | --------------------------- | ------------- |
| 日/小时     | `fut_kline` `cont_adj`（已做）             | `continuous`/`contract` 保留  | ✅             |
| 15/30 分钟 | `fut_kline` `min15`/`min30` `cont_adj` | `bar_15m`/`bar_30m`（合成原版）保留 | ✅ `_adjust_bars.py` 落地 |
| 1 分钟     | **新表 `minute_bar_adj`**（待建）            | 复权后删 raw `minute_bar`       | ❌ 全新管线        |

> 这与你的"5/15/30/60 合成数据保留原版及复权版"完全对齐：`bar_*`=原版，`fut_kline` cont_adj=复权版。

### 2.2 15/30/60m 复权：`_adjust_bars.py`（已验证，替代旧 adjust_fdf 路径）

`adjust_fdf --freq min15` 依赖 `fut_kline.min15.continuous/contract` 帧（非 FG = 0 行），**不可用**。正确路径是直接对 `bar_*` 的 888 序列复权：`runtime/_adjust_bars.py`。

**换月检测（双门，解决"误把隔夜跳空当换月"）**：
1. `is_large = |cc888| > (high-low) + (prev high-low)` —— 888 大跳空；
2. `roll = is_large AND |cc8888| < 0.40×|cc888|` —— 指数连(8888)未同步跳 → 换月断层。
   两端同跳 = 真实市场跳空（隔夜/周末）→ **保留不平移**（否则扭曲收益率）。

**实测（v4 诊断，84 品种 11 年）**：大跳空 35,162 处中**真换月仅 2,802 处**（均值 33/品种，CU=6、AU=12、RS=146，量级合理）；此前单门检测报 76,306 处系把正常隔夜缺口全误判为换月——若照此复权会抹平真实缺口。

**前复权（锚定最新段）**：`cum[i] = Σ_{k>i, roll[k]} cc888[k]`，`adjusted = OHLC + cum`。跨换月 bar 的收盘差复权后 = 0（断层消除），任意两点价差（盈亏点数）不变。

**验证（2026-09-27）**：A888/AG888/AL888/AO888/AP888 复权后"换月型大跳空"残留 **= 0**（市场跳空保留）。✅

写入：`fut_kline(freq=min15/min30/min60, kind='cont_adj', symbol=XXX888)`，COPY 批量装载，先 DELETE 后 COPY 保证幂等。原始 `bar_*` 不动（原版+复权版并存，符合裁定）。

### 2.3 1 分钟复权 + 删原始（⚠ 与现有合成链路冲突）

`minute_bar`（云端 1.14 亿行/38G）是 `bar_*` 的**唯一事实来源**（`_minute_and_bars_job`：收 1 分钟→合成 5/15/30/60）。若"复权后删 raw"，须同步改造该 job 为：

```
收 raw 1min → 写 minute_bar_adj（复权）→ 从 adj 合成 bar_* → 删 raw minute_bar
```

否则删 raw 会**直接打掉合成链路**。这是代码改造，不是单纯跑脚本。

## 三、后续入库冲突（必须解决）

1. **删 raw `minute_bar` 破坏合成**：见 §2.3，须配套改 `_minute_and_bars_job`。
2. **云地同步表不一致**：`sync_cloud_local` 默认表列表含 `bar_15m/30m/60m,fut_kline,...` **但不含 `minute_bar`**。若本地删 raw 1min、云端保留 raw，会双端漂移。需把 `minute_bar`/`minute_bar_adj` 纳入同步白名单（或明确单向）。
3. **15m 复权先有源再跑**：否则产生"假复权 cont_adj"，比缺失更危险（§2.2）。
4. **取数口径混淆**：回测须明确用 `fut_kline.cont_adj`（复权）还是 `bar_*`（原版），避免重演本次 WB 误查 cont_adj 而漏掉 bar_15m。
5. **因子数据空**：`factor_value` 无写入逻辑，因子回测/接入（PRD T1~T7）仍"待开发"。
