> 生成时间：2026-09-27

## 3. 核心表详细设计

### 3.1 `fut_kline`（统一原始行情超表）
- **PK**：`(freq, kind, symbol, trade_datetime)`
- 字段：`freq text`, `kind text`, `symbol text`, `trade_datetime timestamptz`, `open/high/low/close numeric(20,4)`, `volume bigint`, `oi bigint`, `adj numeric(20,4)`, `src text`
- 来源：天勤 天勤 拉取（`fetch_fdf.py`），日/小时为主，min15 仅一次性人工抓取 FG。
- 索引：按 `(symbol, trade_datetime)` 的 hypertable 分块；查询需带 `freq`+`kind` 过滤。

### 3.2 `bar_15m` / `bar_30m` / `bar_60m`（合成分钟级 K 线）
- **PK**：`(symbol, bucket)`
- 字段：`symbol text`, `bucket timestamptz`, `open/high/low/close numeric`, `volume bigint`, `amount numeric`, `open_interest numeric`
- 来源：`fetch_contract_1min.py` 由 `minute_bar` 逐级 `time_bucket` 合成。`bar_15m` 8,845,980 行 / 168 合约（全品种），止于 2025-12-31；`minute_bar` 实测 114,305,280 行、`bar_5m` 24,086,684 行，合成链路源完整。
- **2026-09-27 实测：云端 `bar_15m`/`bar_5m`/`bar_30m`/`bar_60m`/`minute_bar` 与本地逐位一致（行数、逐 symbol 行数+sum(volume)+max(ts) 全同）。wb 反馈"仅 FG 有 15 分钟"来自其本地 CSV `E:\QH\SX\qi_signal_FG_min15.csv`，非云端库——云端数据齐全。**

### 3.3 `warehouse_receipt`（仓单日报）
- **PK**：`(report_date, exchange, symbol, warehouse)`
- 字段：`report_date date`, `exchange text`, `symbol text`, `warehouse text`, `receipt_qty bigint`, `change_qty bigint`, `unit text`, `src text`, `version text`
- 来源：`collect_warehouse_receipt.py`（SHFE/CZCE 日线 API + DCE/GFEX 浏览器逐日 upsert）。当前 720,967 行，四所均至 2026-09-24。

### 3.4 `member_position_rank` / `member_position_rank_summary`（会员持仓排名）
- `member_position_rank` **PK** `(trade_date, exchange, symbol, member, version)`：逐会员明细 `rank`,`long_pos`,`short_pos`,`long_chg`,`short_chg`,`vol_pos`,`src`。
- `member_position_rank_summary` **PK** `(report_date, symbol, version)`：top5/10/15/20 的 `vol_*`、`long_open_interest_*`、`short_open_interest_*` 共 24 个聚合数值列 + `variety`,`src`。
- 来源：`collect_member_rank_summary.py` 读 `member_position_rank` 聚合写入 summary。

### 3.5 `factor_registry` / `factor_value`（因子）
- `factor_registry` **PK** `(factor_id)`：`name`,`category`,`description`,`data_sources text[]`,`min_history_days`,`horizon`,`lag_days`,`enabled`,`default_weight`,`max_weight`,`version`。（**当前空，未 seed**）
- `factor_value` **PK** `(factor_id, trade_date, symbol)`：`raw_value`,`z_value`,`available_at`,`version`。（**当前空，无任何写入逻辑**）
- 现状：因子计算脚本 `factor_ic_scan.py` / `factor_pairs_ic.py` 只产出 **CSV/MD 文件**（`scripts/factor_pairs_out/`），不写库。

### 3.6 其它基本面 / 基础表
- `inventory` PK `(report_date, exchange, symbol, warehouse, version)`：`inventory_qty`,`receipt_qty`,`unit`,`change_qty`。
- `spot_basis` PK `(report_date, symbol, version)`：现货价、近/主力合约价、`near_basis`,`dom_basis` 等。
- `roll_yield` PK `(report_date, symbol, version)`：近/远月价与滚动收益率（当前空）。
- `daily_bar` PK `(symbol, trade_date)`：OHLC + settle + 收益率（`ret_close/settle/5/20`）。
- `hourly_bar` PK `(symbol, trade_datetime)`：小时线 + `ret`,`src`。
- `main_continuous` / `main_contract_map` / `contract_daily` / `contract_code_map` / `futures_symbol` / `trade_calendar`：品种/合约映射与主连复权。

### 3.7 模型 / 回测 / 运维
- `prediction_result` PK `(run_id, symbol)`：方向、概率、收益区间、置信度、state。
- `backtest_result` PK `(run_id, symbol, model)`：方向准确率、MAE、RMSE、分状态 jsonb。
- `backtest_detail` PK `(run_id, symbol, model, eval_date)`：逐日明细。
- `anomaly_ticket`：数据质量异常工单（akshare vs 天勤 差异）。
- `fusion_*` / `pipeline_*` / `briefing_signal` / `task_run`：信号推送与流水线记录。

## 4. 15 分钟数据缺口专项（wb 回测阻塞点）

**现象（已澄清）**：wb 反馈「服务器只有 FG 有 15 分钟数据」。

**结论（2026-09-27 实测）**：**云端 `bar_15m` 含有全品种 168 合约共 8,845,980 行，与本地逐位一致**；`minute_bar`(114,305,280)、`bar_5m`(24,086,684)、`bar_30m`、`bar_60m` 云端均=本地。wb 的"仅 FG"源于其回测脚本 `imports/SX/_wangye_min15.py` 读取的是**本地 CSV** `E:\QH\SX\qi_signal_FG_min15.csv`（仅 FG），并非云端 Postgres。故**云端 15 分钟数据完整，不存在缺失**。

**wb 回测取数修正**：
- 直接查询云端 `bar_15m`（`SELECT * FROM bar_15m WHERE symbol='<品种>888' ORDER BY bucket`）即可获得全品种 15 分钟；或
- 由云端导出逐品种 15 分钟 CSV 供其 DolphinDB 使用。

**持续增量（长期）**：当前 `bar_15m` 止于 2025-12-31（合成链路 `minute_bar` 未持续跑）。要保持云端 15 分钟持续更新，需开启 `FutKlineConfig.freqs` 的 `min15` 采集（路径 B）或常驻 `minute_and_bars` 合成（路径 C）。一次性历史已通过部署迁移（PRD §14.2）完整上云。
