## 2. 模块级走查结论

### 2.1 预测系统（CB，M1–M6）— 完整、运行正常
- M1 数据层、M2 特征/单模型、M3 集成/传导、M4 回测、M5 看板、M6 小时线/因子 均已落地。

- `/health` 显示 `ready=true`、最新数据 2026-09-16、lag 1 天。

### 2.2 融合策略引擎（PRD §6）— 与 PRD 高度一致、运行中
- `fusion_state_detail` 实现：EMA140 方向层 + MA20 回踩重启/10根突破入场 + 2×ATR 初始止损 + 2×ATR 吊灯 + 0.5R 保本 + close-only，与 PRD §6.1–6.6 一致。
- `config.fusion.*` 全部默认参数与 PRD §6.7 完全对齐：`ema_k=140 / atr_n=14 / ma_n=20 / sl_atr=2.0 / trail_atr=2.0 / be_r=0.5 / W=60 / entry_mode=both_nm / cooldown_bars=3 / min_bars=160 / max_bars=400`。
- 运行验证：`/fusion/positions` 返回 50 品种、26 个非中性持仓（含入场价、止损位、保本状态）→ **引擎确实在跑并产出信号**。

### 2.3 信号推送层（PRD §7）— 已实现
- 融合扫描 `minute="*/15"`（✓ §7.1）；状态机去重（`FusionPosition` 持久化 + 冷启动基线）；三段式推送（新信号/止损变动/盘前+30min 简报/待执行复提）；`pushplus` 主通道 + `fallback_webhook` 降级；`fusion_push_log` 留痕；`push_windows` 三个时段 + 非交易日冻结（✓ §7.2–7.5）。

### 2.4 数据层与小时线（PRD §4）— 大部分满足，逐根增量有偏差
- 双表架构落地：`daily_bar`/`hourly_bar`/`main_continuous` + 回测底座 `fut_kline` 超表。
- 日线更新：每日三档 cron（**实际 08:00/12:30/20:00**，见 §4 P2 与 PRD 不一致）。
- 小时线：每小时 `:00` 整段重抓+upsert（`hourly_src=akshare` 单源），含定稿守卫。
- **复权已接入调度**：`_adjust_job` 每日 02:30 遍历 50 品种 × (hourly,daily) 调 `adjust_fdf.run`（✓ 解决 PRD §4.2 与旧文档"复权未接调度"的担忧）。

### 2.5 回测与研究模块（PRD §8）— ❌ **未实现**
- 系统中**不存在**融合策略两层回测（`bt_symbol`）、参数面板、四维矩阵、walk-forward、多 seed。
