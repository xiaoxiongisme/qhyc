| git 冲突文件清单 | 见 §5，含双方新增文件（CB 原清单漏列 WB 新增）|

**口径铁律（已在统一 PRD §4.6 写明，两边必须遵守）**
- 运行时表 `daily_bar`/`hourly_bar` = akshare 口径（小时线信号实时用，读 `hourly_bar` 唯一 src）。
- 回测底座 `fut_kline` = 天勤 tqsdk 口径（含复权 `cont_adj`，回测唯一权威）。
- **禁止双源混读**：两个 K 线口径（akshare 结束时刻标 / tqsdk 起点标）会被当成两根喂指标，砍半周期。
