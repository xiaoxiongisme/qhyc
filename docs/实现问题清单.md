## 2026-09-07 ｜ M2.1 平滑主连自动延伸（R1 完整落地）

### 逆向验证结论（实现前对用户数据做了两组实证）

1. **用户的平滑算法不可精确复刻**：`diff=adj-raw` 有 48 个变化点（换月仅 20 次），
   2020-07 出现连续 7 天渐变、9 个换月日无变化、`delta` 仅部分匹配
   `new.close-old.close`——用户是混合规则（渐变加权 + 平移），非简单差价/比例复权。
   **决策**：不逐点复刻历史公式；延伸段只需"收益率无换月跳空 + 水平锚定 CSV 末日"。
2. **持仓量法主力判定可用**：close_oi 最大者为主力，与用户 rolls.csv 日期差 2~4 天
   （用户为"确认后延迟移仓"口径）——延伸段与用户历史 rolls 无重叠日期，无一致性冲突。
   实测修正了一个误判：FG 8 月中旬并未来回 1/5/9 循环外的月份，真实换月为
   **2026-08-14 FG609→FG701**（FG701 oi 99 万 > FG609 98.6 万），已用合约数据核实。

### 实现方案（比例平滑法）

| 环节 | 规则 |
|---|---|
| 候选合约 | 用户 contracts.json 已知合约 → 推断主力月码循环（**按出现频次过滤**，剔除移仓偶经月份如 FG010/011/012）→ 生成后续 3 个月码 |
| 换月检测 | tqsdk 拉候选合约日 kline，逐日 close_oi 最大者为主力（平手用 volume）；拉取失败自动重建会话重试 1 次 |
| 平滑收益率 | 换月日 ret = **新合约自身两日收益**（N(d)/N(d-1)-1，消除拼接伪跳空）；其余日 = raw 主连收益 |
| 水平锚定 | adj(t) = adj(t-1) × (1+ret/100)，从 CSV 末日 adj_close 起链式衔接 |
| OHLC | adj_open/high/low = raw × (adj_close/raw_close)；volume 用 raw |
| 落库 | main_continuous 延伸行 `src='csv_smooth_ext'`；新换月入 main_contract_map `src='inferred'` |
| 联动 | scheduler 三次 ingest 与手动 `/ingest` 均在**预测前**自动延伸；CLI `scripts/extend_smooth.py` |

### 实测（2026-09-07）

- FG：延伸 17 行（2026-08-13 ~ 09-04），检出换月 8/14 FG609→FG701；换月日 adj 收益 -0.97%
  （FG701 两日真实收益）而非 raw 拼接伪值，**序列无跳空**
- SA：延伸 15 行（2026-08-17 ~ 09-04），窗口内无换月（SA609 仍为持仓主力）
- **FG888 预测口径已回归 `csv_smooth`**（M2 的滞后回退不再触发），实现 R1 全链路单一口径
- 换月记录 `main_contract_map` 新增 `inferred` 源（FG609→FG701 @2026-08-14）

### 已知限制 / 备注

- tqsdk 3.7.5 `query_quotes` 参数不兼容（`ins_class`），候选合约改由月码循环生成——
  若未来主力月码跳出循环（如新上市月份），需人工在 config/contracts.json 补充
- 尚未上市的远月候选（如 SA709）拉取失败仅为警告，自动跳过
- 用户 rolls.csv 的换月日比 oi 切换日晚 2~4 天；延伸段使用 oi 切换日口径，
  与用户历史口径的日期差异不影响收益率正确性（换月日收益始终取新合约自身收益）

## 2026-09-08 ｜ M4.1：LSTM walk-forward 回测（遗留项闭环）

### 实现（`BacktestParams.lstm_retrain_every=60` 根）

- 回测窗口按线上重训节奏**分段**（250 日 ≈ 4~5 段），逐段生成"段起点前"快照：
  训练数据 = `df[df.index < 段首评估日]` 最后 250 根（严格早于段内全部评估日）
- 每段快照 `train_until = 段前最后一日`；段内评估点加载 `train_until ≤ t` 的最新快照
  （复用审计 P1 的 `_select_weight_path` 机制）
- `update_current=False`：回测快照**不覆盖线上权重**，线上仍由周训维护

  两个分段文件正确落盘；`FG888__20260903/04.pt` 为线上周训快照（并行不冲突）

### ⑳ LSTM 权重冻结解除

- 泄漏已机制性根治（walk-forward 快照无前视），`lstm_weight_freeze` 改为
  **null（默认不冻结）**——权重月更按 walk-forward 准确率正常更新 LSTM
- 如需重新冻结（如怀疑新泄漏），config 填数值即可

### 效果与语义变化

- 回测语义从"单快照贯穿全程"（陈旧模型偏差）升级为**walk-forward**：
  忠实模拟线上"每周重训"行为，LSTM 的回测分数即为"定期重训策略"的历史真实表现
