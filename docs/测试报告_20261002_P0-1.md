## 3. 测试中发现的问题与修复

| # | 问题 | 根因 | 修复 | 状态 |

## 4. 数据层阻塞（生产上线前必须解决，非代码问题）

1. **`main_contract_map` 覆盖严重不足**
   - 仅 **2 个品种**（FG 21 行、SA 17 行），`distinct product = 2`。
   - RB/AG/AU/I/MA/TA/BU/HC 等主流品种**完全缺失** → 反解在合约选择阶段即 BLOCK（见 2.3，8/10 品种阻断）。
   - **需建/启“每日主力合约映射刷新”作业**，写入全部品种当周主力合约到 `underlying`。

2. **`main_contract_map` / `contract_daily` 新鲜度陈旧**
   - `main_contract_map` FG 最新映射日 `2026-08-14`、SA 仅 `2026-04-15`；当前日期 2026-10-02。
   - `contract_daily` 中 FG2701/SA2609 数据止于 `2026-09-09`。
   - 导致 2.3 的 3.45%/3.82% 偏差部分源于两端新鲜度不齐；且 SA2609 已临近/越过交割月。
   - **需保障采集管线对主力合约日频价的持续更新**。

3. **`futures_symbol.price_tick` 未填充** → tick 对齐校验当前跳过（仅 WARN）。
   - 可由 `seed_price_tick.py --apply` 派生 50/73（见 2.5），余下需补充行情源。

4. **前端静态资源** `GET /assets/ -> 404`（前端产物挂载路径待核）。
