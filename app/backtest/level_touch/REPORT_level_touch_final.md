# level_touch 点位触达回测 · 全链路结论报告（终稿）

> 生成日期：2026-10-25
> 模块：`app/backtest/level_touch/`（分支 `cb/level-touch-backtest`）
> 数据：`barstore` 未复权连续主连（`caliber='continuous'`，绝对价位研究在方法论上站得住）
> 口径：次根开盘成交 + bar 内止损止盈（无前视）；换月/涨跌停（|收益率|>limit_excl）剔除；成本走 `app.data.cost`

---

## 0. 一句话结论

点位触达策略**不是全市场普适的"圣杯"**，而是一个**需要精选市场 + 精选方向 + 精选周期**的打法。
样本内看似强（全市场选优 +44万 / 白名单组合 322万），但经 **walk-forward 样本外验证后大幅衰减**
（日线 OOS PF 中位 0.90，仅 42% 折叠盈利）。真正跨样本外稳健的有 **8 个品种**
（AG/AU/JM/RU/SC/SF/SR/SS；其中 RU、SC 的 edge 在 60m 周期才显，见 §3.5），
且**最佳周期因品种而异**（SC/RU 在 60m 才显 edge，其余日线最优）。

## 2. 全市场扫描（样本内，须谨慎解读）

- 162 组合 × 59 品种 = 9558 次回测，落盘 `sweep_results.csv`。
- **参数敏感度极平坦**：多头各维度 PF 中位恒在 0.92–0.93，空头 0.85–0.90。
  → 盈亏**取决于选市场/方向，而非调参**。没有"神奇参数"能救差品种，也没有参数能放大好品种。
- 强边缘口袋（样本内）：SR（PF≈4.6）、AU/AG（贵金属）、SC（原油）、LC/SS/SA/NI（工业）。
- **诚实修正**：旧版"全市场 +44万"是 S3 死代码（lookback=None 导致从不触发）造成的虚高，
  实为 S2 单边；真实含 S3 的全市场多头 ≈ **−6.1万**。本报告一切数字均基于修正后代码。

## 3. walk-forward 样本外验证（关键，防过拟合）

- 方法：扩展窗切分（F1: 训练≤2019→测2020-21；F2: ≤2021→测2022-23；F3: ≤2023→测2024+）。
  训练窗选参（PF≥1 且 n≥10 取净利最大），测试窗在全历史回测后**仅统计测试期成交**。
- 范围：白名单 22 品种（样本内改善者）。有效折叠 55（21 品种 × 3 折叠，部分数据不足跳过）。

**整体结果（有 OOS 成交的 48 个折叠）：**
- IS PF 中位 **1.58** → OOS PF 中位 **0.90**，平均衰减 **−0.55**。
- OOS PF>1 占比仅 **42%**；OOS 净利合计 **+112,547 元**（远小于样本内择优 322万）。

**结论：样本内选优存在严重过拟合，扫描里的"强边缘"不能直接当作实盘预期。**

**OOS 真正稳住的白名单子集（PF 中位>1 且 净>0 且 PF>1 占比≥50%）：**
```
AG(1.11/67%/+111k)  AU(1.12/67%/+95k)  JM(1.09/67%/+40k)
SC(1.16/100%/+107k) SF(7.43/100%/+33k) SR(3.70/100%/+12k) SS(1.39/100%/+5k)
```
→ **验证通过白名单 = {AG, AU, JM, SC, SF, SR, SS}（7/22）。**

OOS 翻车的白名单成员（即便样本内改善）：RB(0.39)、I(0.52)、RM(0.23)、P(0.48)、
NI(0.87,−22k)、LH(0.57,−47k)、TA、FU 等——**应从部署白名单剔除**。
**例外 RU**：日线翻车（0.61）属**周期选错**而非策略失效，见 §3.5 在 60m 上的验证；
NI 的 60m edge 仍待补做 walk-forward。

## 3.5 分钟级 walk-forward 验证（RU / SC @ 60m）

针对 §4 深挖发现的「SC/NI/RU 日线亏损、分钟级翻正」，对 RU、SC 在 **60m** 周期**重做**
扩展窗 walk-forward（与 §3 同一切分与选参准则，仅周期不同；数据已 NaN 兜底 + 时区统一）。
落盘 `level_touch_results/wf_60m/`。

**RU @ 60m（日线曾全翻车 0.51/0.04/0.72）：**

| 折叠 | IS PF | OOS PF | OOS n | OOS 净利 |
|------|-------|--------|-------|----------|
| F1 | 1.74 | **1.28** | 30 | +12,674 |
| F2 | 1.59 | 0.74 | 12 | −5,255 |
| F3 | 1.54 | **1.04** | 28 | +1,990 |

→ OOS PF 中位 **1.04**，净利合计 **+9,409**，PF>1 占比 **67%**（3 折累计净利均为正）。

**SC @ 60m（日线已稳健 1.05/1.27，此处更强）：**

| 折叠 | IS PF | OOS PF | OOS n | OOS 净利 |
|------|-------|--------|-------|----------|
| F1 | 1.69 | **1.11** | 134 | +70,890 |
| F2 | 1.48 | **1.63** | 122 | +478,290 |
| F3 | 1.38 | **1.12** | 169 | +162,663 |

→ OOS PF 中位 **1.12**，净利合计 **+711,843**，PF>1 占比 **100%**。

**合计（60m）：** OOS PF 中位 **1.12**，PF>1 占比 **83%**（对比日线白名单的 42%），净利合计 **+721,252 元**。

**结论：**
1. **日线"RU 翻车"是周期误判，不是策略失效**——60m 三折叠 2/3 盈利且累计净利全正，
   RU 的 edge 真实存在于分钟级。已纳入 `VALIDATED_SHORT`，`BEST_FREQ["RU"]="60m"`。
2. **SC 在 60m 更优**：信号密度高一个量级（n 134/122/169 vs 日线 ~10–27），PF>1 占比 100%，
   `BEST_FREQ["SC"]` 维持 60m。
3. **分钟级 walk-forward 是验证分钟级 edge 的必要步骤**——只看日线会误杀 RU 这类品种。
4. 仍待补做：**NI @ 60m**（日线翻车 0.87，深挖 60m/15m 翻正，需同法验证）。

## 4. 分钟级深挖（信号密度 vs 信号质量）

对 9 强边缘品种跑 daily/60m/15m（白名单配置）：

| 品种 | daily PF/net | 60m PF/net | 15m PF/net | 最佳周期 |
|------|------|------|------|------|
| SR | 3.03 / +25k | 0.91 / −3k | 0.70 / −28k | **daily** |
| AU | 1.67 / +415k | 1.52 / +481k | 0.97 / −39k | daily(净60m略高) |
| AG | 1.43 / +137k | 0.96 / −23k | 0.84 / −127k | **daily** |
| SC | 0.80 / −200k | **1.20 / +291k** | 0.79 / −478k | **60m** |
| LC | 1.45 / +34k | **1.60 / +70k** | 1.25 / +24k | 60m |
| SS | 1.26 / +12k | 1.04 / +4k | 0.53 / −225k | daily |
| SA | 0.86 / −9k | 0.75 / −27k | 0.57 / −54k | 无 edge |
| NI | 0.94 / −15k | **1.21 / +59k** | 1.19 / +64k | 60m/15m |
| RU | 0.75 / −63k | **1.14 / +50k** | 1.11 / +35k | 60m/15m |

**结论：**
1. **信号密度随频率升高 ✔ 证实**：所有品种 n_trades 单调上升（SR 27→97→539；AU 87→286→1327）。
2. **但"高频=更好 edge" ✘ 不普适**：对 AU/AG/SR/SS，高频稀释 edge、转为亏损；
   对 **SC/NI/RU/LC**，日线反而亏损、分钟级才揭示 edge（这类品种的日线噪声掩盖了结构）。
3. **最佳周期因品种而异**——必须逐品种选周期，不能一刀切。
4. 数据质量：分钟级数据含 NaN 行（SC/LC/SS/SA/NI 等），已修复 `backtest.py`
   在回测入口 `dropna(subset=[open,high,low,close])`，否则 `make_grid` 的 `int(NaN)` 会崩溃。

## 5. 部署形态（`variety_config.py`）

```python
from app.backtest.level_touch.variety_config import config_for_variety
cfg = config_for_variety("AU")   # 默认 validated=True → allow_short=True, freq=daily
cfg = config_for_variety("SC")   # allow_short=True, freq=60m（其 edge 在分钟级）
cfg = config_for_variety("CU")   # allow_short=False（不在白名单）
```
- `WHITELIST_SHORT`（22）：样本内候选池，含过拟合，**不直接用于实盘**。
- `VALIDATED_SHORT`（8）：walk-forward 验证通过的严格白名单（日线 7 + 60m 加 RU），**部署默认走此集**。
- `BEST_FREQ`：逐品种推荐周期（SR/AU/AG/JM/SF/SS→daily；SC/RU→60m）。
- `run_portfolio(品种列表)`：按各自配置跑并聚合，输出 `portfolio_summary.csv`。

## 6. 诚实边界与风险

1. **所有结果均为样本内 / 样本外历史回测**，含前视防护但本质是数据挖掘，存在残余过拟合。
2. **walk-forward 主为日线**：RU/SC 的 60m edge 已补做 walk-forward 验证（见 §3.5，均稳健）；
   **NI 的 60m edge 仍待补做验证**（日线翻车 0.87、深挖 60m/15m 翻正）。
3. 成本用历史费率（commission+slippage），未含滑点冲击在低频品种的放大效应。
4. 换月缺口剔除基于 `limit_excl` 阈值，极端行情可能误剔/漏剔。
5. 策略**非市场中性**，净值高度依赖少数品种（SR/SC/AU/AG）的表现，组合集中度高。
