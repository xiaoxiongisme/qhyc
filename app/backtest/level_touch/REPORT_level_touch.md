# level_touch 点位触达回测 · 结论报告（全市场扫描版）

> 分支：`cb/level-touch-backtest` · 提交：`a5d3f19`
> 数据区间：2015-01-01 至今 · 标的：郑/大/上/能/广期所全市场 **59 个**连续主连品种
> 运行：在 `qhyc-api` 容器内 `barstore.load(variety,'daily','continuous')` 取**未复权**连续主连

---

## 1. 这一版做了什么

| 项目 | 内容 |
|---|---|
| 多周期 | 支持 `daily / 60m / 15m`，参数按 `bars_per_day` 缩放（warmup/hold/atr/limit_excl 等）|
| 空头对称 | `allow_short` 开启后 S1/S2/S3 生成镜像空头信号，离场按强支撑/强阻力反向 |
| 参数扫描 | `sweep()` 全市场日线网格搜索，输出 `sweep_results.csv` + 稳健性汇总 |
| 选择性空头 | 扫描后处理推导出「哪些品种开空头更优」的白名单 |
| 诚实结论 | 修正旧版 S3 死代码导致的虚高收益，如实汇报 |

本次扫描规模：**162 组合 × 59 品种 = 9558 次回测**，容器单核 ~17 分钟完成。

---

## 2. 方法学口径（铁律）

1. **只用未复权连续主连**（`barstore caliber='continuous'`）。后复权会平移历史价位，使「该价位是否被触及」失真，故**绝对价位研究一律禁用后复权**。本模块默认即未复权。
2. **次根开盘成交**：决策用 `t` 日收盘，成交用 `t+1` 日开盘；止损/止盈在 `t+1` 日 bar 内判定，**无前视**。
3. **成本唯一权威** `app.data.cost`（历史费率/乘数/tick/滑点）；未知费率即报错，绝不以 0 成本静默计算。
4. **换月/涨跌停剔除**：`|日收益| > limit_excl(日线 10%)` 的 bar 既不计入触达图，也不作为信号日。
5. **强价位用正向 z 分数**：`z >= z_thr`（触达频率显著高于均值）才记为支撑/阻力，避免把「价格刻意绕开」的价位误当支撑。

---

## 3. 核心发现

### 3.1 边缘是「选市场 + 选方向」问题，不是「调参」问题

对 `n_trades>=10` 的子集，各参数维度的盈利稳健性（中位 PF / 盈利占比）**几乎不变**：

| 维度 | 多头 PF 中位 | 多头盈利占比 | 多空 PF 中位 | 多空盈利占比 |
|---|---|---|---|---|
| support_z_thr 1.5/2.0/2.5 | 0.92 / 0.93 / 0.93 | 41–42% | 0.88 / 0.87 / 0.86 | 35–37% |
| stop_atr_mult 1.5/2.0/3.0 | 0.92–0.93 | 41–42% | 0.89 / 0.87 / 0.85 | 32–38% |
| target_atr_mult 2/3/4 | 0.92–0.93 | 40–43% | 0.89 / 0.86 / 0.86 | 33–39% |
| s3_no_return_p_thr 0.5/0.6/0.7 | 0.94 / 0.91 / 0.92 | 41–44% | 0.86 / 0.85 / 0.90 | 34–39% |

**结论**：把 `support_z_thr / stop / target / s3_p_thr` 在合理区间内任意取值，组合的中位 PF 都稳定在 0.85–0.93。盈亏不取决于精调参数，而取决于**选对品种和方向**。这反而是好事——策略对参数不敏感，鲁棒；但也意味着没有「神奇参数」能拯救差品种。

### 3.3 强边缘口袋（PF>1.2 & 净利>0 & 成交>=20 的组合，共 60 个）

高度集中于少数品种：
- **SR 白糖**：PF 高达 **4.6**，是最稳的单品种边缘（多头、空头、各参数组合均稳居前列）。
- **贵金属 AU/AG**：长期正漂移 + 回调买入(S1) + 突破回踩(S2) 共振。
- **软商品 SC(原油)/LC(碳酸锂)/SS(不锈钢)/SA(纯碱)/NI(镍)/A(豆一)**。
- 这些品种的共性：**高波动、趋势性强、存在可识别的支撑/阻力与突破结构**。

### 3.4 整体中位 PF < 1（诚实汇报）

全网格的中位 PF ≈ 0.9，说明**策略并非全市场普适**。它只在「精选市场 + 正确方向」的子集上有效。把它当全市场通用策略会亏损；当作「选股式」的精选打法才有价值。

### 3.5 组合层效果（样本内）

- 全多头、逐品种取最优配置：**组合净利 ≈ 232 万元**（59 品种可比子集）
- 应用空头白名单（22 个开空头、其余纯多头）：**组合净利 ≈ 322 万元**
- **白名单带来 +89 万元组合提升**（样本内，且依赖逐品种选最优配置）

## 4. 诚实的结论与局限

1. **样本内选择偏差（最重要）**：本报告所有「最优」都来自对 **9558 个组合**的择优，存在显著过拟合风险。白名单与强边缘组合**必须经 walk-forward / 样本外验证**后方可用于实盘或信号。
2. **未复权连续主连的换月跳空**：虽用 `limit_excl` 剔除极端单根，但跨合约的长期触达图仍受换月跳空扰动，长期（多合约）强价位识别的可靠性低于近期窗口。S2(ATH 突破) 与 S3(坑结构) 用近期窗口，受此影响较小。
3. **S3「难回买价」已真实化且在商品上多亏**：旧版因死代码 `lookback_days=None` 导致 S3 从不触发，+44 万实为 S2 单边；本版 S3 真实运行后，在商品上 PF 常 <1（追高后难回的概率被高估）。S3 不宜单独依赖。
4. **空头默认关闭的合理性**：多数商品正漂移，盲目做空会把正期望品种拖成负期望；故默认 `allow_short=False`，仅对白名单品种选择性开启。
5. **成本敏感**：所有结论已含 `app.data.cost` 真实成本；若成本假设下调，边缘会进一步收缩。

---

## 5. 建议下一步

1. **白名单样本外验证**：对 22 个空头品种 + 多头强边缘品种做滚动 walk-forward（如 2015–2020 训练选参，2021–今验证），确认边缘在样本外存活。
2. **分钟级深挖**：对白名单/强边缘品种跑 `60m / 15m`（信号密度更高），验证日线边缘在更细粒度是否依然存在、是否更早治疗。
3. **选择性空头部署**：把白名单做成 `allow_short` 的按品种配置（而非全局开关），与多头强边缘组合并运行。
4. **成本/滑点压力测试**：在成本上浮 20–50% 情形下复测，确认边缘稳健。

## 6. 复现方式

```bash
# 在 qhyc-api 容器内
docker exec -it qhyc-api env PYTHONPATH=/app python -m app.backtest.level_touch.sweep
#   -> 默认跑代表性小集合；全市场日线见 run_full_sweep.py

PYTHONPATH=/app python app/backtest/level_touch/run_full_sweep.py
#   -> /app/qh/level_touch_sweep_out/sweep_results.csv

PYTHONPATH=/app python app/backtest/level_touch/report_sweep.py
#   -> selective_short_whitelist.csv + sweep_analysis.md
```

输出物已归档至 `level_touch_results/sweep_out/`：
`sweep_results.csv`（9558 行明细）、`sweep_summary.md`、`sweep_analysis.md`、`selective_short_whitelist.csv`。
