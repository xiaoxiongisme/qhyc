两版「抓大波动」引擎 · A / B 回测

目标：EG 9–10 月大波动 V5X 因 P2 高波日禁开仓而空仓，另起两套独立引擎尝试吃这段行情。 同一成本模型 / 预热 / EOD / OOS(2026) 口径。数据截至 2026-10-16。

一句话结论：A（波动扩张突破）与 B（偏离回归）在 EG/EB 上都不赚钱——A 被 60m 化工的反复假突破来回打脸，B（逆势摸偏离）在大波动趋势里被一路碾压。 这恰好反证了 V5X 的 P2「高波日禁开仓」不是 bug，而是有效的风控：9–10 月这种行情对朴素系统是绞肉机。

1. 两版引擎定义

Route A｜波动扩张突破

入场：当根 ATR/近20根ATR均值 ≥ vol_ratio（波动扩张） 且 收盘 > 前N根最高（或 < 最低）且 c > o。
方向：随突破方向（不叠加 EMA140 方向门，避免与突破冲突）。
离场：2ATR 初始止损 + 2ATR 吊灯 + 0.5ATR 保本。

Route B｜偏离回归 (emadist)

入场：|收盘 − EMA140| / ATR ≥ dev_thr（大幅偏离均值）。 偏离在上 → 做空回归；偏离在下 → 做多回归。
方向：逆偏离（摸均值回归）。
离场：价格回到 EMA140（止盈）+ 2ATR 硬止损 + 0.5ATR 保本。

5. 为什么两版都失败（机制解释）

① 化工 60m 是「趋势中夹噪音」结构：突破（A）在趋势延续前先被回抽触发 2ATR 止损，反复磨损； 试算 A 在 EG 上 2026 仅 7 笔就 −10,592，样本极少但方向明确（OOS 亏）。

② 大波动 = 高 ADX = 强趋势，逆势摸偏离（B）必然被碾压：价格偏离 2.5ATR 后还能再走 5–6ATR， 2.5ATR 的止损太窄、回归目标（EMA140）太远，胜率仅 26–28%，成本一吃就转负（EG PF 0.83 / EB 0.69）。

③ MA 是唯一在 B 上 2026 转正的品种（+7,798 / PF1.29），因为甲醇的均值回归性更强； 但这只说明「哪个品种适合回归」，不说明「大波动可稳定套利」。

6. 那 EG 的大波动到底怎么参与？

诚实答案：不建议用 A/B 这类 60m 朴素系统去硬吃。 证据在表里——两版都亏，且亏损集中在趋势段。 可行的方向只有两条，且都需要额外验证：

方向一（推荐）：接受 V5X 的设计。 P2 高波日空仓不是缺陷，是它避开绞肉机的核心。等平波日的 EMA140 回踩再入， 这正是 V5X 在 EG 上 38–41% 胜率、PF 2.6–3.3 的来源。

方向二：若坚持要波动暴露，做成「体制自适应」而非「摸偏离」。 即：高波日只做同向趋势跟随、止损放宽到 3–4ATR、并且降低单笔仓位（因为高波日 ATR 大）， 再用「波动收缩后离场」而非固定目标。这是一套独立的小系统，需单独 OOS 验证，不能与 V5X 混仓。

7. 纪律与局限

① EG/EB 的 A 样本极少（EG 37 笔、EB 25 笔），结论方向可信但幅度置信宽；B 样本充分（EG 715 / EB 684），结论稳健。

② 本报告已修复一个隐蔽 bug：EG/EB 60m 序列起始有 6/9 根全 NaN 棒，手写递推 ATR 遇 NaN 会永久中毒（首 14 根均值含 NaN → 全序列 NaN → 0 信号）。 已用「丢弃 NaN 棒」修复，修复前 A/B 在 EG/EB 上均 0 笔（假象）。此为项目记忆里「NaN 僵尸仓」同源问题。

③ 参数为小网格扫描，存在隐式过拟合；靠逐品种 + OOS(2026) 双向看，未做单点最优挑选。

④ 上线前仍需：EG/EB 双品种并发风控叠加对拍、真实滑点压力测试。
