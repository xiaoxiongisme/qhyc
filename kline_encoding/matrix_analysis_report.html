线性代数把“为什么预测不动方向”变成了一个投影问题。 把每根K线当作 5 维标准化向量 z，滞后协方差 Γ₁=Cov(z_t, z_(t+1)) 的典型相关分析给出线性可预测性的硬上限： 平均可预测方差仅 9.1%（MA）/7.3%（EG）， 且几乎全部集中在振幅坐标（逐坐标 R²：振幅 23.6% vs 涨跌 2.2% vs CLV 0.1%）。 几何表述：把 y（下一根涨跌）向 X（当前 5 特征）的列空间做正交投影，投影长度只占 y 中心化长度的 1.3%—— 残差向量仍是原向量的 98.7%，预测值是垂直于残差的一根细针。残差正交性校验 5.7e-15（机器精度）证明最小二乘解的正确性。
VIF 指出编码丢掉了全场唯一正交的坐标。五个特征的方差膨胀因子：振幅 1.0（与任何其他坐标都不共线）、 上影/下影 1.7、涨跌幅 2.9、CLV 4.4。六位码把 5 维压成 3 个二值位后，振幅维只剩 11.9% 捕获率（CLV/影线维 74~84%）—— 丢的恰好是最独立、最可预测（PC3 可预测性 42.7% 全场最高）的那一维。格拉姆矩阵则显示 8 个状态质心只张成 2.65 维： 八态标签虽然多，几何上接近一个 2.7 维的云——“实体方向 × 影线模式”两个因子就几乎说完了。

十、结论：矩阵视角的五条工程结论

1. 转移矩阵说“形状无记忆”：谱间隙 0.87、驻留 1.0~1.3 根、平稳分布与经验分布只差 0.17pp——八态动力学是一个合格的马尔可夫链，但混合太快，形态本身不能当状态机用。
2. 滞后协方差说“可预测性全在振幅方向”：平均线性可预测方差 9.1%，逐坐标 R² 振幅 23.6% / 涨跌 2.2% / CLV 0.1%；范数自相关 0.205 vs 振幅坐标 0.491——波动率聚集住在单个坐标里，不在整个向量里。
3. 协方差矩阵说“有效维度 3.7，正交坐标只有振幅”：参与率 3.68、VIF 振幅=1.0；六位码在振幅维只捕获 11.9%，在 CLV/影线维捕获 74~84%。
4. PCA 说“一根K线是 3 维物体”：PC1 位置（39%）、PC2 方向（23%）、PC3 大小（21%），三轴 83%；六位码 = PC2 的 1bit + PC1 的 2bit + PC3 的 0bit。
5. 日×时段矩阵说“波动率可分离、低秩”：σ₁ 独占 72.5%、有效秩 5.4；日载荷预测次日振幅（0.64）不预测方向（−0.067）——仓位标定的矩阵基础。
6. 距离矩阵给八卦映射一个诚实判决：聚类结构 = 实体方向 × 影线模式；错卦对最远（符合直觉），综卦对并不近（CLV 翻转）——命名法好用，几何学不成立。
