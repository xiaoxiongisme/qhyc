② 五层架构

判断顺序有严格先后：每根 bar 先维护枢轴点 → 冷却递减 → 检查离场 → 检查进场 → 检查加码。进场成功的当根不再加码；平仓当根冷却置 7，冷却期内不得开仓。

③ 信号层：什么形态可以进场

3.1 方向过滤（唯一允许的方向）

dir[t] = sign(close[t-1] − EMA140(close)[t-1]) ← 用【前一根】的方向 做多只允许 dir ≥ 0，做空只允许 dir ≤ 0
为什么用前一根：防止当根收盘自己同时决定「方向」和「触发」造成自我强化；也用前一根保证了无前视。EMA140（≈1 个月）是生产引擎的既定口径，方向层调快被实证不改善入场时点（研究结论 18：「晚的是确认不是方向」）。

3.2 回踩支路（Pullback，主力支路）

多头四条件（同时成立，价格均为当根收盘/高低）： ① dir ≥ 0（方向允许多） ② 上穿：close[t] > EMA20[t] 且 close[t-1] < EMA20[t-1] ③ 触及：low[t] ≤ EMA20[t] ← 本根真的回踩过均线 ④ 斐波汇流：取最近 60 根内最后一个枢轴低点 PL， 腿 = PL 到其后最高点 SH 的幅度 leg = high[SH] − low[PL]（要求索引距 ≥2 且 leg>0） 要求 low[t] 落在 {SH − r×leg | r ∈ 0.382/0.5/0.618} 之一 ± 0.5×ATR14 内 空头完全镜像（下穿 + 触及 + 自枢轴高点的反弹位汇流）
白话：上涨趋势里，价格跌回 20 小时均线、且恰好跌在上一段涨幅的 38.2%–61.8%「黄金回撤区」，才认为这是一次「健康的回调结束」，此时顺大势买入。研究依据：「买回调本身（不等确认）净利 −30.6%」——所以必须等到「重新站上均线」这一确认动作，等确认本身就是 edge（研究结论 18）。

3.3 突破支路（Breakout，非化工品种适用）

多头：dir ≥ 0 且 close[t] > max(high[t-10 … t-1]) 且 close[t] > open[t]（阳线） 空头镜像。前 10 根不含当根。
为什么化工链禁用这条支路（P4）：审查发现化工池（聚酯/聚烯烃/两碱/醇醚）的突破单毛利为负——化工品种假突破多、趋势延续性差。所以 V5X 中这四条链只做回踩，其余板块（黑色/有色/贵金属/农产品等）双支路都允许。

3.4 ADX 趋势强度门

ADX14[t-1] ≥ 15 才允许任何进场（前一根口径） 注：本策略 ADX 内部用 EMA(span=14) 递推（非 Wilder），前 28 根输出 0 —— 与生产引擎一致，不要随意「修正」
ADX<15 的震荡市里，回踩和突破都容易被双向打脸。15 是生产策略既定参数，未在本轮研究中重调。

④ 门控层：五道过滤器（本策略的 alpha 来源）

优先级按下列顺序依次判定，任一触发则信号作废（sig→0）。所有门控都只用 ≤ 当根收盘可得的信息。

P2 · 高波日禁开仓 采纳

hvol(td) = 1{ 昨日振幅 > 250 日振幅序列的 80 分位 }（滚动窗 min_periods=60，shift(1)） hvol=1 的交易日，全天（含夜盘归属日）禁止新开仓；已有持仓的止损/吊灯照常运行
证据：策略审查发现高波日入场的 903 笔合计亏 −100.7 万。高波日的回踩/突破多数是情绪尖峰而非趋势启动，止损 2ATR 在高波日等于把止损放在噪声带里。数学依据：波动是聚类的体制变量（HMM 三态），高波体制下该策略的入场边缘为负。例外纪律：只禁「新开仓」，不强制平掉旧仓——旧仓有自己的止损管理。

P4 · 化工链只回踩 采纳

CLUSTER(品种) ∈ {聚酯, 聚烯烃, 两碱, 醇醚} ⇒ 突破支路信号强制作废 涉及 15 个品种：TA PX PF PR / PP L V EB / FG SA SH / MA EG UR
证据：化工池突破支路毛利为负（剔除单品种 IF 后 −13.4 万）；化工品种受原油夜盘与产业套保盘影响，小时级突破多为假动量。扩展到全部能化（P4E）反而稀释收益，故保持原四条链。

P6 · 尾盘根不开仓 采纳

sess_last = 日盘 14:00 根 ∪ 夜盘收盘前最后一根完整小时（按品种夜盘时长自适应，SC 等跨零点品种已处理） 落在会话末根的信号作废
证据：尾盘入场紧跟着长休市，隔夜跳空风险全额暴露且无法用日内止损响应；尾盘成交清淡，收盘价易被尾盘单扭曲（第二章「极端收盘回拉只值 1.3bp」的另一面）。注意只禁末根，早盘根（B2）经检验不禁。

M1a · MACD 柱同号门（仅回踩支路）采纳

hist[t-1] = 2×(DIF−DEA)，DIF=EMA12−EMA26，DEA=EMA9(DIF) 回踩做多要求 hist[t-1] ≥ 0；回踩做空要求 hist[t-1] ≤ 0。突破支路不适用此门。
证据（59 品种全市场口径）：KDJ 金叉但 MACD 柱仍绿（hist<0）的多单，胜率低 12.5 个百分点；镜像的空单低 12.6pp；48/49 个品种方向一致。机制（心理学依据）：回踩进场的本质是赌「回调已结束」，而 MACD 柱还在反方向说明动能尚未扭转——你是在接一把还在下落的刀。反向对照（要求柱反号才做）显著更差，证明信息为真。只用于回踩支路是因为突破支路的逻辑恰恰是「动能刚启动」，柱滞后不适用。

M5 · 会员净持仓强度门 采纳

z = member_net_z（最新 available_at ≤ 当根交易日的值；严格滞后，NaN 放行） |z| ≥ 1.0 才允许开仓；方向不设要求（M5b 方向一致版无增量，未采纳） 阈值敏感性：0.5 → 135 万；1.0 → 148 万（单因子口径）；1.5 → 94 万 ⇒ 1.0 为甜点
证据：单因子 M5 全市场 MAR 4.67（全部变体中最高）；反向对照（只在 |z|<1 开仓）−49.2 万。机制（社会学依据）：会员席位净持仓是产业资本与大户的「真金白银投票」，z 分数衡量其偏离常态的程度；|z| 大说明知情资金立场鲜明，此时技术信号与之共振的胜率显著更高。注意 V5X 采纳的是强度门而非方向门——大户绝对立场鲜明的「天气」比立场方向本身更稳定（方向版 M5b 无增量）。

簇冲击日封禁 环境基线

对 17 个板块各算「簇等权日收益」r_cl(td)，冲击日 = { |r_cl| > 3×σ_250d } 冲击日当日该簇全部品种禁止新开仓
依据：第二章证实跨品种共尾真实量级 2–4× 且是体制变量——簇冲击日就是共尾兑现日，此时簇内任何「独立信号」都是同一个宏观冲击的回声，分散是错觉。此规则在 BASE 与所有变体中一致生效，属策略环境而非增量门控。

⑤ 执行层：进场后怎么管

5.1 进场执行

  • 触发时点：60m bar 收盘确认（所有条件按收盘价判定），订单在下一根 bar 开盘以市价/对手价执行。
  • 回测口径：按信号根收盘价成交 + 双边滑点（slip_ticks×tick，每品种实测档）+ 真实费率。实盘滑点已被成本模型覆盖，预期偏差在 1 tick 内。
  • 首仓 1 手（固定手数口径；组合层资金分配见 ⑧ 局限）。

5.2 止损三件套（全部以「入场根的 ATR14」e_atr 为尺子，持仓期间不重新计算）

多头（空头镜像，peak→trough，−→+）： 初始止损 stop = avg_price − 1.75 × e_atr 吊灯止损 stop = max(stop, peak_close − 2.0 × e_atr) ← 只紧不松 保本规则 一旦 close − entry_price ≥ 1.0 × e_atr，stop 抬到 entry_price（至少保本） 触发判定 close ≤ stop ⇒ 当根收盘价离场（实盘：下一根开盘市价单）
设计逻辑：初始止损 1.75ATR（V5X.2 自进化重扫由 1.5 放宽至 1.75，降低噪声扫损同时保留趋势空间）；吊灯 2.0ATR 让利润奔跑（V5X.2 由 3.0 收窄至 2.0，更快锁定盈利）；1.0ATR 保本把「猜对了方向但走不远」的单子变成免费彩票。止损/保本/冷却于 2026-10-22 经持仓周期参数扫描（无 bug 代码）重锁：SL 1.5→1.75、TRAIL 3.0→2.0、BE 1.0 保持、COOLDOWN 1→7、ADD_THR 1.5 保持（见文末 V5X.2 勘误）。

5.3 阶梯加码（最多 2 手）

多头：close[t] > max(high[entry … t-1])（创入场以来新高，不含当根） 且 close[t] − entry_price ≥ 当前手数 × 1.5 × e_atr ⇒ +1 手，均价重算 进场当根不加码；加码后止损按新均价与新 peak 重算（e_atr 不变）
「浮盈够一整个 ATR 且价格创新高」才加——加码用的是市场已经证明你正确的钱，而不是摊平亏损。利弗莫尔阶梯口径，与生产一致。

5.4 冷却与节奏

  • 平仓后冷却计数置 7，逐根递减，冷却期间不得新开仓。2026-10-22 曾由 3→1 缩短，经无 bug 代码全量重扫发现 COOLDOWN=7 综合最优（离场后冷却更充分、抑制过拟合噪声），故重锁为 7。
  • 数据末端仍持仓的，按最后一根收盘价强制平仓记账（回测口径）。

5.5 成本模型

round_cost = fee_open(入场原始价) + fee_close(离场原始价) + 2 × slip_ticks × tick fee_close 分 CLOSETODAY（同一交易日）/ CLOSE_YEST（隔日）两档，PCT 费率 = fee_value÷10000 × 价 × 乘数 净盈亏 = (离场 − 均价) × 手数 × 乘数（复权价）× 方向 − round_cost × 手数

⑦ 实盘运行 SOP 与停机条件

7.1 每日盘前（T 日开盘前，全自动）

  1. 更新前一交易日日线 → 重算每品种 amp 与 250 日 80 分位 → 得 hvol(T)。
  2. 重算 17 簇等权日收益与 3σ 冲击标记 → 得每品种 blocked(T)。
  3. 拉取 member_net_z：取 available_at ≤ T 的最新值（一般为 T−1 持仓，次日上午可得）；无数据置 NaN（放行）。
  4. 按交易日历计算当日各品种的会话末根小时集合（夜盘归次日）。
  5. 向 56 个 SymbolEngine 分发 DailyCtx。

7.2 每根 60m bar 收盘后（全自动）

  1. 写入当根 OHLCV（复权+原始价）→ on_bar()。
  2. 引擎返回订单列表：OPEN / ADD / CLOSE（含数量与原因）。
  3. 下一根 bar 开盘执行；记录实际成交价与回测假设价的偏差，纳入滑点监控。
  4. 持仓中每根都要重算吊灯/保本止损位（引擎内建）。

7.3 监控指标（每日收盘后）

  • 滚动 60 笔 PF：<0.8 亮黄牌，<0.7 亮红牌。
  • 当月回撤 vs 历史 MDD（59.6 万，固定 1 手口径）：超过 1.5×（≈89 万）触发停机评审。
  • 单品种净利占比：TOP1 超过 40% 提示集中度风险（当前剔 TOP1 仍 +35.8 万）。
  • 数据健康：member_z 连续 5 日 NaN 的品种告警（M5 失效中）；60m bar 缺口检测。
  • 成交偏差：实盘成交价 vs 信号根收盘价的滚动均值，超 2×slip_ticks 告警。

7.4 停机条件（kill switch，任一触发即停止新开仓）

  • 滚动 60 笔 PF < 0.7；
  • 净值回撤超过历史 MDD 的 1.5 倍；
  • 费率/保证金规则重大调整未重测（成本模型过期）；
  • member_net_z 因子数据源中断超过一周（M5 门长期失效等于换了策略）。
上线前检查清单：① 引擎与回测逐位对拍通过（见 ⑨）；② 用生产组合引擎（资金分配/保证金占用层）对 V5X 信号流重跑一遍，确认组合口径净值形状一致（教训 16/19：输入口径与「已修复」声明都要自证）；③ 纸面跟踪 ≥20 个交易日，比对实盘信号与研究信号逐根一致；④ 费率档核对交易所最新公告。

⑧ 已知局限（必须知情）

  1. 固定 1 手逐品种口径，没有组合层。+134 万是 56 品种各 1 手的简单加总，不含保证金占用、资金分配与相关性约束；实际上线规模需生产组合引擎复核后才能定。
  2. holdout 只有 195 笔（2026 年 9 个多月），PF 1.22 与训练期 1.223 几乎一致是好信号，但样本仍小，且历史最大回撤（−59.6 万）恰好发生在 holdout 段。
  3. 胜率 24% 意味着连续亏损 8–12 笔是常态。心理压力是执行风险的一部分——这正是门控条款「一条不许放松」的原因：放松门控=交易更多=更接近基线的 PF 1.03。
  4. M5 依赖外部因子源。member_net_z 的 available_at 纪律若被破坏（拿到未公布的数据时间），回测全部失效——这是全策略最脆弱的一根链条，务必保持滞后纪律。
  5. 成交假设：信号根收盘价成交 + 固定滑点。极端行情（涨跌停附近）成交可能显著劣于假设，簇冲击日封禁已部分对冲该风险。
